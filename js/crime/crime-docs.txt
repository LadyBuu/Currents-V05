# 1. SYSTEM OVERVIEW

## Purpose

The Crime & Law System manages all criminal activities, legal enforcement, and vendettas within the game world. It provides:

- **Crime Recording** - Track all crimes with full details
- **Dynamic Law Enforcement** - Laws come from Religion and Government systems
- **Dual Legal Systems** - Civil laws (secular) + Religious laws (spiritual)
- **Law Aggregation** - Combines laws from both systems for enforcement
- **Vendetta Management** - Full tracking of blood feuds between households
- **Supremacy Rules** - Theocracy vs secular law application
- **Crime Statistics** - Comprehensive analytics across locations
- **Rich Crime Data** - Type, severity, violations, punishments

## Key Design Principles

| Principle | Description |
|-----------|-------------|
| **Single Source of Truth** | `crime-state.js` holds all crime and vendetta data |
| **Command-Query Separation** | Commands (writes) vs Queries (reads) separated |
| **Separation of Concerns** | State, commands, queries, laws, UI all separate |
| **Dynamic Law Enforcement** | Laws are NOT hardcoded - read from Religion/Government |
| **Recursion Guards** | All public functions protected from infinite loops |
| **Household Integration** | Crimes affect household prestige, criminal counts |
| **Settlement Integration** | Crimes affect settlement crime rates and prosperity |
| **No Emojis** | All icons from `icons.js` via `_getIcon()` |

### Supremacy Rules

#### `CrimeLawIntegration.applySupremacyRules(violations, locationId)`

| Property | Value |
|----------|-------|
| **Description** | Applies supremacy rules based on settlement government type |
| **Parameters** | `violations` (Object), `locationId` (string) |
| **Returns** | `{ civil: [], religious: [], all: [] }` |

**Supremacy Rules:**
- **Theocracy**: Religious laws override civil laws

# 12. LAW INTEGRATION FLOW

## When a Crime Occurs

```
1. User triggers action (murder, theft, heresy, etc.)
   ↓
2. CrimeCommands.triggerMurder() / triggerExecution() called
   ↓
3. CrimeLawIntegration.getApplicableLaws(characterId, domain)
   ├── Gets character's religion (if any)
   ├── Gets character's location
   ├── Gets civil laws from settlement (GovernmentLaws)
   └── Gets religious laws from religion (ReligionLaws)
   ↓
4. CrimeLawIntegration.checkLawViolations(characterId, action, context)
   ├── Checks each applicable law against the action
   ├── Returns civil violations and religious violations
   └── Returns all violations
   ↓
5. CrimeState.recordCrime(data)
   ├── Records crime with violations attached
   ├── civilViolation: { lawId, lawName, punishment, ... }
   ├── religiousViolation: { lawId, lawName, punishment, ... }
   └── violatedLaws: [{ source, lawId, lawName, sourceId, sourceName }]
   ↓
6. Consequences applied
   ├── Victim dies (if murder)
   ├── Killer executed (if caught and murder illegal)
   ├── Households updated (prestige loss)
   ├── Settlement updated (crime rate)
   └── Event logged
```

## Law Applicability Rules

| Scenario | Civil Laws | Religious Laws |
|----------|------------|----------------|
| Secular settlement | Apply to ALL residents | Apply to FOLLOWERS only |
| Theocracy | None (empty) | Apply to ALL residents |
| Established Church | Apply to ALL residents | Apply to ALL + state religion influence |
| Independent Courts | Apply to ALL residents | Apply to FOLLOWERS (separate courts) |

## Example 1: Recording a Murder with Law Checking

```javascript
// Get victim and killer
var victim = window.getCharacterById('char_123');
var killer = window.getCharacterById('char_456');

// Trigger murder with law checking
var result = window.CrimeCommands.triggerMurder(
    victim.id,
    killer.id,
    {
        year: 1250,
        reason: 'Jealousy',
        killerGotAway: false,
        startVendetta: true,
        notes: 'Murdered in the night'
    }
);

if (result.success) {
    console.log('Murder recorded');
    console.log('Law violations:', result.data.lawViolations);
    console.log('Civil punishment:', result.data.civilPunishment);
    console.log('Religious punishment:', result.data.religiousPunishment);
}
```

## Example 2: Getting Applicable Laws for a Character

```javascript
// Get laws for a character
```
