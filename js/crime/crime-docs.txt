# CRIME & VENDETTA SYSTEM - COMPLETE DOCUMENTATION

## SYSTEM OVERVIEW

The Crime & Vendetta System manages all criminal activities, executions, blood feuds, and vendettas within the game world. It provides a complete API for recording crimes, tracking executions, managing vendettas between households, and analyzing crime statistics across locations.

**Key Design Principles:**
- **Single Source of Truth**: `crime-state.js` holds all crime and vendetta data
- **Command-Query Separation**: Commands (writes) vs Queries (reads) separated
- **Separation of Concerns**: State, commands, queries, constants, UI all separate
- **Recursion Guards**: All public functions protected from infinite loops
- **Household Integration**: Crimes affect household prestige, criminal counts, and victim counts
- **Settlement Integration**: Crimes affect settlement crime rates and prosperity
- **Vendetta Tracking**: Full tracking of blood feuds between households and characters
- **Rich Crime Data**: Type, severity, reason, punishment, solution, witnesses, evidence

---

## FILE STRUCTURE

```
js/core/crime/
├── crime-state.js              # Single source of truth + cache + notifications
├── crime-commands.js           # All write operations (murder, execution, vendetta)
├── crime-queries.js            # All read operations (stats, trends, filters)
├── crime-constants.js          # All constants (types, severities, punishments)
├── crime-ui-stats.js           # UI statistics rendering
├── modals-crime.js             # UI modals (murder, execution, vendetta, details)
└── vendetta-system.js          # Standalone vendetta management

js/core/modals/
├── modals-crime.js                 # Crime modals
├── modals-char-select.js           # Character selector
└── modals-household-selector.js    # Household selector
```

## Murder Command

### `CrimeCommands.triggerMurder(victimId, killerId, options)`

| Property | Value |
|----------|-------|
| **Description** | Triggers a murder with full consequences |
| **Parameters** | `victimId` (string), `killerId` (string), `options.year` (number), `options.reason` (string), `options.killerGotAway` (boolean), `options.startVendetta` (boolean), `options.locationId` (string), `options.notes` (string) |
| **Returns** | `{ success: boolean, data: { victim, killer, murderReason, killerGotAway, year, crime, execution, vendetta, householdUpdates } }` |

**Integration Effects:**
- Records crime in CrimeState
- Kills victim character
- Executes killer if caught
- Creates blood feud vendetta if requested
- Updates victim's household (prestige loss, criminal count, victim count)
- Updates killer's household (prestige loss, criminal count)
- Updates settlement crime rate and prosperity

### `CrimeCommands.triggerExecution(condemnedId, options)`

| Property | Value |
|----------|-------|
| **Description** | Triggers an execution |
| **Parameters** | `condemnedId` (string), `options.year` (number), `options.reason` (string), `options.method` (string), `options.executionerId` (string), `options.locationId` (string), `options.isForMurder` (boolean), `options.victimId` (string), `options.endRelationships` (boolean), `options.notes` (string) |
| **Returns** | `{ success: boolean, data: { condemned, reason, method, year, crime, householdId } }` |

**Integration Effects:**
- Records execution as a crime
- Kills condemned character
- Ends all active relationships if requested
- Updates condemned's household (prestige loss, executed count)
- Updates settlement crime rate

### `CrimeCommands.createBloodFeud(victimId, killerId, options)`

| Property | Value |
|----------|-------|
| **Description** | Creates a blood feud from a murder |
| **Parameters** | `victimId` (string), `killerId` (string), `options.year` (number), `options.cause` (string), `options.notes` (string) |
| **Returns** | `{ success: boolean, data: Object }` |

**Integration Effects:**
- Creates or updates vendetta
- Records first death in vendetta
- Updates both households
- Updates settlement crime rate
