# Crime & Law System — Domain Documentation

Version: 6.0 (refactor complete)
Replaces: `crime-docs.txt`
Owns: `crimes`, `vendettas` on `masterData.data`
Depends on: Character, Household, Location, Settlement, Religion, Industry

---

## 1. Ownership contract

The Crime domain owns exactly two canonical arrays on `masterData.data`:

| Array | Shape | Owner |
|---|---|---|
| `crimes` | `[{ id, type, perpetratorId, perpetratorName, victimId, victimName, year, reason, locationId, witnesses[], evidence[], solved, solvedAt, solution, punishment, method, severity, recordedAt, notes, metadata, civilViolation, religiousViolation, religionId, violatedLaws[] }]` | Crime |
| `vendettas` | `[{ id, householdAId, householdAName, householdBId, householdBName, characterAId, characterAName, characterBId, characterBName, cause, originCrimeId, startedYear, status, deaths[], escalatedAt, resolvedAt, resolution, notes, createdAt, updatedAt }]` | Crime |

Crime **does not** own:

| Data | Owner | Read via | Written via |
|---|---|---|---|
| Character identity, death, professions | Character | `getCharacterById`, `getCurrentLocationId` (global) | `killCharacter`, `CharacterCommands.addProfession` (for profession additions) |
| Household membership, prestige, crime history | Household | `getHouseholdById` | `HouseholdCommands.applyPerpetratorCrime` / `applyVictimCrime` / `applyExecutionToHousehold` |
| Places, leaders, government assignment | Location | `getPlaceById`, `getCurrentLocationId` | — |
| Government type, justice severity, watch, settlement wealth/debt, civil laws | Settlement | `SettlementQueries.getSettlementData`, `SettlementLawQueries.getCivilLaws`, `SettlementReligionQueries.getDominantReligion` | `SettlementGovernmentCommands.setJusticeSeverity` / `setWatch`, `SettlementLawCommands` |
| Religious laws, religion membership | Religion | `ReligionLaws.getLawsByReligion`, `ReligionQueries.getReligion` / `getAllReligions` | — |
| Enterprises and their impact on settlement income | Industry | `IndustryQueries.getIndustryTaxRevenue` / `getIndustryEnterpriseStats` | — |
| Relationships | Character | `getRelationshipsForCharacter`, `endRelationship` (globals) | those same globals |

Cross-domain **writes** go through the owning domain's commands. Cross-domain **reads** go through the owning domain's queries. Crime code never writes into another domain's canonical arrays.
