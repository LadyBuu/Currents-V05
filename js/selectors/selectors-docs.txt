# 1. SYSTEM OVERVIEW

## Purpose

The Selector System provides reusable UI components for selecting entities (characters, households, locations) throughout the application. All selectors are built on a common foundation that ensures consistent behavior, styling, and user experience.

## Key Principles

| Principle | Description |
|-----------|-------------|
| **Core Only** | Selectors depend ONLY on core modules (no system dependencies) |
| **Single Source of Truth** | Each selector type has one canonical implementation |
| **Reusable Components** | All selectors share a common base with consistent API |
| **No Inline Styles** | All styling via CSS classes in external stylesheet |
| **No Emojis** | All icons from icons.js |
| **Event Delegation** | Efficient event handling via delegation |
| **Proper Cleanup** | All event listeners are cleaned up on destroy |
| **Recursion Guards** | Protection against re-entrant calls |

# 2. ARCHITECTURE

## File Structure

```
js/
├── core/
│   ├── query-helpers.js          # Core query utilities (NO system deps)
│   ├── selector-base.js          # Shared selector base class
│   ├── modals-core.js            # Modal manager + core wrappers
│   ├── formatting.js             # HTML escaping
│   ├── icons.js                  # SVG icons
│   ├── accessors.js              # Data access
│   └── time.js                   # Time calculations
│
├── selectors/
│   ├── locationDropdown.js       # Hierarchical location dropdown
│   ├── modals-char-selector.js   # Character selector modal
│   └── modals-household-selector.js # Household selector modal
│
└── css/
    └── selectors.css             # All selector styles
```

## Core Principles

### 1. Core Has NO System Dependencies

All core files (`query-helpers.js`, `selector-base.js`, `modals-core.js`) must NOT depend on any system files (relationship-registry, household-state, etc.).

### 2. Selectors Depend Only on Core

All selector files depend ONLY on core modules. They do NOT directly access system files.

### 3. Data Queries Are Centralized

All data querying logic is centralized in `query-helpers.js` and `accessors.js`. Selectors call these functions rather than implementing their own queries.

### 4. Event Management

- Event delegation is used for list item clicks (single listener on parent)
- All listeners are tracked and cleaned up on destroy
- No `cloneNode` workarounds

### 5. Styling

- ALL styling via CSS classes in `selectors.css`
- NO inline styles in JavaScript
- Responsive by default

### Functions

#### `openCharacterSelector(options)`

Opens the character selector modal.

**Options:**

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `title` | string | 'Select Character' | Modal title |
| `targetId` | string | null | Target character ID for filtering |
| `onSelect` | Function | function() {} | Called when character selected |
| `onCancel` | Function | function() {} | Called when cancelled |
| `excludeIds` | Array | [] | Character IDs to exclude |
| `preset` | string | null | Filter preset |
| `filters` | Object | {} | Filter options |

**Filter Presets:**

| Preset | Description |
|--------|-------------|
| `'partner'` | Single, age 21-30, peers |
| `'father'` | Male, age 31-40, has children |
| `'mother'` | Female, age 31-40, has children |
| `'child'` | Age 0-10 |
| `'master'` | Age 31-40 |
| `'apprentice'` | Age 11-20 |
| `'elder'` | Age 61-70 |
| `'available'` | Single, age 21-30 |
| `'all'` | No presets |

**Filter Options:**

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `search` | string | '' | Search term |
| `gender` | string | 'all' | 'all', 'male', 'female' |
| `status` | string | 'all' | 'all', 'single', 'partnered', 'widowed' |
| `ageGroup` | string | 'all' | Age group key |
| `location` | string | 'all' | Location ID |
| `role` | string | 'all' | Role ID |
| `showDeceased` | boolean | false | Include deceased |
| `peers` | boolean | false | Peers (±10 years) |
| `sameLocation` | boolean | false | Same location |
| `hasChildren` | boolean | false | Has children |
| `noChildren` | boolean | false | No children |
| `hasParents` | boolean | false | Has parents |
| `orphan` | boolean | false | Orphan |
| `sortBy` | string | 'age_desc' | 'age_desc', 'age_asc', 'name', 'birth_year' |

**Returns:** `CharacterSelector` instance

#### `closeCharacterSelector()`

Closes the character selector.

### CharacterSelector Class

| Method | Description |
|--------|-------------|

// Open character selector
openCharacterSelector({
    title: 'Select Father',
    targetId: currentCharacter.id,
    preset: 'father',
    onSelect: function(character) {
        console.log('Selected:', character.name);
        // Do something with selected character
    },
    onCancel: function() {
        console.log('Selection cancelled');
    }
});

// With custom filters
openCharacterSelector({
    title: 'Select Partner',
    filters: {
        status: 'single',
        ageGroup: '21-30',
        peers: true,
        sameLocation: true
    },
    onSelect: function(character) {
        // Handle selection
    }
});
```

## Household Selector

```javascript
// Open household selector
openHouseholdSelector({
    title: 'Select Household',
    targetCharacterId: characterId,
    filterConfig: {
        showActive: true,
        showVacant: false,
        locationFilter: locationId
    },
    onSelect: function(household) {
        console.log('Selected household:', household.name);
    }
});
```

## Location Dropdown

```javascript
// Create a location selector component
var selector = createLocationSelector('locationContainer', {
    selectedId: currentLocationId,
    onChange: function(id) {
        console.log('Location changed:', id);
        var place = getPlaceById(id);
        console.log('Name:', place.displayName);
    }
});

// Get/set value
var current = selector.getValue();
selector.setValue(newLocationId);

selector.refresh();
