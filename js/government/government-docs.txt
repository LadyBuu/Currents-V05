## 3. RECURSION GUARDS

All modules implement recursion guards to prevent infinite loops:

| GUARD NAME | LOCATION | PURPOSE |
|------------|----------|---------|
| `_processingCommand` | government-commands.js | Prevent command re-entry |
| `_processingQuery` | government-queries.js | Prevent query re-entry |
| `_processingAssignment` | government-assignment.js | Prevent assignment re-entry |
| `_processingEconomy` | government-economy.js | Prevent economy re-entry |
| `_rendering` | government-ui-list.js | Prevent rendering re-entry |
| `_openingModal` | All modals files | Prevent modal re-entry |
| `_initializingState` | government-state.js | Prevent state re-initialization |
| `_notifyingSubscribers` | government-state.js | Prevent subscriber re-entry |


## 4. ICON POLICY

All icons must come from icons.js via the `_getIcon()` function:

| RULE | DESCRIPTION |
|------|-------------|
| RULE 1 | NO emojis in code or UI |
| RULE 2 | All icons from icons.js via `_getIcon()` |
| RULE 3 | NO icons in confirm/cancel buttons (plain text only) |

**AVAILABLE ICONS USED BY GOVERNMENT SYSTEM:**

| CATEGORY | ICONS |
|----------|-------|
| Basic Shapes | CIRCLE, CIRCLE_DOT |
| Cross/Check | CHECK, CHECK_SIMPLE, X_HEAVY |
| UI Elements | HOME, PERSON, LOCATION, COIN, SEARCH, EDIT, TRASH |
| Status | SUCCESS, WARNING, DANGER |
| Objects | CROWN, STAR_4, BOOK, GEAR |


## 5. DATA STRUCTURES

### Department Object
```javascript
{
    id: string,                    // Unique department ID
    name: string,                  // Department name
    description: string,           // Optional description
    locationId: string,            // Location ID
    parentDepartmentId: string,    // Parent department ID (null if root)
    positions: [],                 // Array of Position objects
    assignments: [],               // Array of Assignment objects
    isDeprecated: boolean,         // Deprecation status
    createdAt: number,             // Year created
    updatedAt: number              // Year last updated
}
```

### Position Object
```javascript
{
    id: string,                    // Unique position ID
    name: string,                  // Position name
    description: string,           // Optional description
    priority: number,              // 1-100 (lower = higher rank)
    parentPositionId: string,      // Parent position ID (null if root)
    requiredRankId: string,        // Required rank (optional)
    minExperience: number,         // Minimum experience years (optional)
    genderRestriction: string,     // 'male', 'female', or 'either'
    salaryOverrides: []            // Array of salary override entries
}
```

### Assignment Object
```javascript
{
    id: string,                    // Unique assignment ID
    positionId: string,            // Position ID
    characterId: string,           // Character ID
    characterName: string,         // Character name (cached)
    startYear: number,             // Year started
    endYear: number,               // Year ended (null if active)
    endReason: string,             // Reason for ending
    title: string,                 // Custom title
    notes: string                  // Additional notes
}
```

### Government Type Object
```javascript
{
    id: string,                    // Unique government type ID
    name: string,                  // Type name
    description: string,           // Optional description
    allowedRankIds: []             // Array of allowed rank IDs
}
```

### Government History Entry
```javascript
{
    locationId: string,            // Location ID
    typeId: string,                // Government type ID
    style: string,                 // Government style
    startYear: number,             // Year started
    endYear: number                // Year ended
}
```
