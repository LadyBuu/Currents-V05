# GOVERNMENT SYSTEM - COMPLETE DOCUMENTATION

## SYSTEM OVERVIEW

The Government System manages all government structures including departments, positions, assignments, government types, leadership, and economic functions (salaries, budgets, tax collection). It provides a clean API for other systems to interact with government entities.

---

## FILE STRUCTURE

```
js/systems/government/
├── government-state.js          # Single source of truth + cache + notifications
├── government-commands.js       # All write operations (departments, positions, assignments, types)
├── government-queries.js        # All read operations (search, filter, stats, leadership)
├── government-economy.js        # Business logic for budgets, salaries, taxes
├── government-assignment.js     # Business logic for qualification and succession
├── government-ui-list.js        # UI list rendering
└── modals-government-*.js       # UI modals (departments, positions, assignments, economy)

js/core/modals/
├── modals-government.js              # Main government modals
├── modals-government-assign.js       # Assignment modals
├── modals-government-departments.js  # Department modals
├── modals-government-economy.js      # Economy modals
├── modals-government-positions.js    # Position modals
└── modals-government-types.js        # Government type modals
```

---

## KEY PRINCIPLES

| Principle | Description |
|-----------|-------------|
| **Single Source of Truth** | `government-state.js` holds all government data |
| **Command-Query Separation** | Commands (writes) vs Queries (reads) separated |
| **Separation of Concerns** | State, commands, queries, economy, UI all separate |
| **Recursion Guards** | All public functions protected from infinite loops |
| **Role Integration** | Positions can require roles from the Role System |
| **Household Economy Integration** | Salaries flow to households; taxes collected from households |
| **No Direct masterData Access** | All access through the state layer |

## Salary Processing Commands

### `GovernmentCommands.processGovernmentSalaries(year, options)`

| Property | Value |
|----------|-------|
| **Description** | Processes all active government salaries for a given year |
| **Parameters** | `year` (number), `options.showToast` (boolean), `options.dryRun` (boolean) |
| **Returns** | `{ total: number, paid: number, failed: number, totalSalaryPaid: number, details: Array, errors: Array }` |

**Salary Flow:**
1. Get all active assignments
2. For each, calculate salary based on position priority, location prosperity, and experience
3. Pay salary to character's household via `HouseholdEconomy.updateHouseholdWealth()`
4. Log all payments

---

## Tax Collection Commands

### `GovernmentCommands.collectHouseholdTaxes(locationId, year, options)`

| Property | Value |
|----------|-------|
| **Description** | Collects taxes from all households in a location |
| **Parameters** | `locationId` (string), `year` (number), `options.taxRate` (number, override), `options.showToast` (boolean), `options.dryRun` (boolean) |
| **Returns** | `{ total: number, collected: number, failed: number, totalTaxCollected: number, details: Array, errors: Array }` |

**Tax Flow:**
1. Get all households in the location
2. For each, calculate tax based on household wealth and tax rate
3. Deduct tax from household wealth via `HouseholdEconomy.updateHouseholdWealth()`
4. Add tax to settlement treasury
5. Log all collections
