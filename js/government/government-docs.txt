# 1. SYSTEM OVERVIEW

## Purpose

The Government System manages all government structures, departments, positions, assignments, leadership, and civil laws within the game world. It provides:

- **Department Management** - Create, update, delete departments with hierarchy
- **Position Management** - Define positions with role requirements and skill levels
- **Assignment Tracking** - Assign characters to positions with full history
- **Civil Laws** - Define and manage settlement civil laws (NEW)
- **Leadership** - Assign leaders to locations with term tracking
- **Justice System** - Justice severity and watch management
- **Industry Integration** - Tax revenue from industry enterprises
- **Settlement Integration** - Government salaries paid from settlement allocations
- **Role Integration** - Positions can require specific roles
- **Salary Management** - Position salary calculation with overrides
- **Hierarchical Structure** - Departments and positions support parent-child relationships

## Key Design Principles

| Principle | Description |
|-----------|-------------|
| **Single Source of Truth** | `government-state.js` holds all government data |
| **Command-Query Separation** | Commands (writes) vs Queries (reads) separated |
| **Separation of Concerns** | State, commands, queries, economy, laws, UI all separate |
| **Recursion Guards** | All public functions protected from infinite loops |
| **No Emojis** | All icons from `icons.js` via `_getIcon()` |
| **Civil Laws** | Settlements define their own civil laws via GovernmentLaws |

# 16. DATA SCHEMAS

## Department Object

```javascript
{
    id: string,                     // 'govdept_1234567890_abc123'
    name: string,                   // 'Ministry of Education'
    description: string,
    locationId: string,
    parentDepartmentId: string | null,
    positions: [PositionObject],
    assignments: [AssignmentObject],
    isDeprecated: boolean,
    createdAt: number,
    updatedAt: number
}
```

## Position Object

```javascript
{
    id: string,                     // 'govpos_1234567890_abc123'
    name: string,                   // 'Minister of Education'
    description: string,
    priority: number,               // 1-100, lower = higher
    parentPositionId: string | null,
    requiredRoleId: string | null,  // Link to role
    minSkillLevel: number,          // 0-100
    genderRestriction: 'either' | 'male' | 'female',
    requiredRankId: string | null,  // Link to rank
    minExperience: number,          // Years
    salaryOverrides: [
        {
            salary: number,
            year: number,
            reason: string
        }
    ]
}
```

## Assignment Object

```javascript
{
    id: string,                     // 'govassign_1234567890_abc123'
    positionId: string,
    characterId: string,
    characterName: string,
    startYear: number,
    endYear: number | null,
    endReason: string | null,
    title: string,                  // Custom title
    notes: string,
    roleIdAtAssignment: string | null,
    skillLevelAtAssignment: number
}
```

## Government Type Object

```javascript
{
    id: string,                     // 'govtype_1234567890_abc123'
    name: string,                   // 'Monarchy'
    description: string,
    allowedRankIds: [string]        // Ranks permitted to hold positions
}
```

## Leader Assignment Object

```javascript
{
    id: string,                     // 'leader_1234567890_abc123'
    characterId: string,
    characterName: string,
    startYear: number,
    endYear: number | null,
    title: string,                  // 'King', 'Mayor', etc.
    isActive: boolean,
    notes: string,
    timestamp: number
}
```

## Civil Law Object (GovernmentLaws)

```javascript
{
    id: string,                     // 'civillaw_1234567890_abc123'
    name: string,                   // 'No Murder'
    type: 'law' | 'taboo' | 'guideline',
    lawCategory: 'civil',
    domain: 'marriage' | 'behavior' | 'worship' | 'food' | 'social' | 
            'economic' | 'political' | 'sexual' | 'violence' | 'death',
    description: string,
    severity: 'minor' | 'major' | 'mortal',
    crimeMapping: {
        crimeType: string | null,   // Link to CRIME_TYPES
        crimeSeverity: number | null, // Override default severity (1-10)
        isEnforced: boolean,        // Is this enforced by law?
        punishment: string | null,  // Default punishment description
        notes: string
    },
    createdAt: number,
    updatedAt: number,
    notes: string
}
```
