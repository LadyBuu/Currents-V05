# GOVERNMENT SYSTEM - COMPLETE DOCUMENTATION

## SYSTEM OVERVIEW

The Government System manages all government structures, departments, positions, assignments, and leadership within the game world. It provides a complete API for government CRUD operations, position management, assignment tracking, leadership (leaders), and justice system integration.

**Key Design Principles:**
- **Single Source of Truth**: `government-state.js` holds all government data
- **Command-Query Separation**: Commands (writes) vs Queries (reads) separated
- **Separation of Concerns**: State, commands, queries, economy, UI all separate
- **Recursion Guards**: All public functions protected from infinite loops
- **Role Integration**: Positions can require roles (generic professions)
- **Settlement Integration**: Government salaries are paid from settlement allocations
- **Industry Integration**: Government collects industry taxes
- **Justice Integration**: Crime rate reacts to justice severity and watch presence
- **Leader History Tracking**: Full leader assignment history with term tracking
- **Hierarchical Structure**: Departments and positions support parent-child relationships

---

## FILE STRUCTURE

```
js/systems/government/
├── government-state.js              # Single source of truth + cache + notifications
├── government-commands.js           # All write operations (depts, positions, assignments, leaders)
├── government-queries.js            # All read operations (search, filter, stats, leadership)
├── government-economy.js            # Salary calculation and requirements (for settlement allocation)
├── government-assignment.js         # Business logic for qualification and succession planning
├── government-ui-list.js            # UI list rendering
├── government-system.js             # Wrapper for backward compatibility
└── modals-government-*.js           # UI modals (departments, positions, assignments, economy)

js/core/modals/
├── modals-government.js                 # Main government modals
├── modals-government-assign.js          # Assignment modals (bulk, history, succession)
├── modals-government-departments.js     # Department modals
├── modals-government-positions.js       # Position modals
├── modals-government-economy.js         # Economy modals (budget, salary, tax)
├── modals-government-ui.js              # UI modals
└── modals-char-select.js                # Character selector
```

## Constants

### Government Types Structure
Government types define the structure of governance for locations. They include:
- `id`: Unique identifier
- `name`: Display name (e.g., "Monarchy", "Republic", "Theocracy")
- `description`: Description of the government type
- `allowedRankIds`: Array of rank IDs permitted to hold positions

## Salary Calculation

### `GovernmentEconomy.calculatePositionSalary(positionId, department)`

| Property | Value |
|----------|-------|
| **Description** | Calculates salary for a position |
| **Parameters** | `positionId` (string), `department` (Object) |
| **Returns** | `number` - Salary amount |

**Calculation Factors:**
1. Position priority determines tier
