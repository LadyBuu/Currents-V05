**DEPENDENCIES:** None (pure RNG)

**ICON POLICY:** No emojis. No icons.

### CONSTANTS

| Constant | Type | Description |
|----------|------|-------------|
| `RNG_CONSTANTS` | Object | MIN_YEAR: -10000, MAX_YEAR: 9999, DEFAULT_MAX_AGE: 120, MIN_FERTILITY_MODIFIER: 0.5, MAX_FERTILITY_MODIFIER: 1.5, DEFAULT_FERTILITY_MEAN: 1.0, DEFAULT_FERTILITY_STD_DEV: 0.2, SEED_STORAGE_KEY: 'stillwaters_rng_seed' |

### CORE RNG (Seedable)

**ICON POLICY:** No emojis. No icons.

| `ID_PREFIXES` | Object | CHARACTER: 'char', PLACE: 'place', RANK: 'rank', ROLE: 'role', HOUSEHOLD: 'house', RELATIONSHIP: 'rel', EVENT: 'event', etc. |
| `ID_CONFIG` | Object | DEFAULT_RANDOM_LENGTH: 8, SHORT_RANDOM_LENGTH: 4, LONG_RANDOM_LENGTH: 12, MAX_ID_LENGTH: 100, MIN_RANDOM_LENGTH: 4, SEPARATOR: '_' |

### BATCH ID GENERATION
