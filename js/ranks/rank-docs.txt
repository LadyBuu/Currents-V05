# COMPLETE RANK SYSTEM DOCUMENTATION

## SYSTEM OVERVIEW

The Rank System manages hierarchical ranks, titles, and nobility structures in the game world. Ranks define a character's social standing, inherited positions, and formal titles. The system supports numbered ranks (e.g., King Henry VIII), inheritance rules, surname generation, spouse inheritance, and automatic issue detection with one-click fixes.

**Key Principles:**
- **Single Source of Truth:** `rank-state.js` holds all rank data
- **Command-Query Separation:** Commands vs Queries separated
- **Numbered Ranks:** Automatic numbering with ordinal or reign-based systems
- **Inheritance Rules:** Define which ranks inherit from others
- **Surname Rules:** Auto-generate surnames based on rank and location
- **Spouse Inheritance:** Ranks can be inherited through marriage
- **Gender Restrictions:** Ranks can be restricted to specific genders
- **Deprecation:** Ranks can be deprecated on death
- **Issue Detection:** Auto-detection of rank configuration problems with auto-fix
- **Integration:** Works with Relationship System, Family System, and Character System

## RANK-ISSUES.JS

**PURPOSE:** Auto-detection and auto-fix of rank configuration issues. Integrates with the Relationship System and Family System.

### Issue Types Checked

| Issue Type | Severity | Description | Auto-Fix |
|------------|----------|-------------|----------|
| **Spouse Inheritance** | Error | Spouse not receiving rank upon marriage | ✅ Adds inherited rank |
| **Child Inheritance** | Warning | Children not receiving parent's rank | ✅ Adds inherited rank |
| **Gender Mismatch** | Error | Wrong gender holding restricted rank | ✅ Deprecates rank |
| **Numbering Issues** | Error/Warning | Incorrect birth order numbering | ✅ Renumbers all holders |
| **Deprecation Issues** | Error | Rank not deprecated on death | ✅ Deprecates rank |
| **Broken Inheritance Rules** | Error | Rules referencing non-existent ranks | ✅ Removes broken rules |

### Main Functions

| Function | Parameters | Returns | Description |
|----------|------------|---------|-------------|
| `RankIssues.checkAll()` | None | `Object` | Checks all issues and returns results |
| `RankIssues.checkSpouseInheritance()` | None | `Array` | Checks spouse inheritance issues |
| `RankIssues.checkChildInheritance()` | None | `Array` | Checks child inheritance issues |
| `RankIssues.checkGenderMismatch()` | None | `Array` | Checks gender mismatch issues |
| `RankIssues.checkNumberingIssues()` | None | `Array` | Checks numbering issues |
| `RankIssues.checkDeprecationIssues()` | None | `Array` | Checks deprecation issues |
| `RankIssues.checkBrokenInheritanceRules()` | None | `Array` | Checks broken inheritance rules |

### Return Structure

```javascript
{
    success: true,
    issues: [RankIssue, ...],
    count: 3,
    bySeverity: {
        error: [...],
        warning: [...],
        info: [...]
    }
}
```

### RankIssue Object

| Field | Type | Description |
|-------|------|-------------|
| `type` | string | Issue type (e.g., 'Spouse Inheritance') |
| `severity` | string | 'error', 'warning', or 'info' |
| `message` | string | Human-readable description |
| `rankId` | string | Related rank ID (if applicable) |
| `characterId` | string | Related character ID (if applicable) |
| `rankName` | string | Rank name (resolved) |
| `characterName` | string | Character name (resolved) |
| `fix` | function | Auto-fix function (if available) |
| `fixLabel` | string | Human-readable fix label |
| `fixData` | object | Data used for the fix |

### Integration with Relationship System

The Issues System uses the REAL relationship system:

| Check | Uses |
|-------|------|
| **Spouse Inheritance** | `RomanceLogic.getPrimaryPartner()` |
| **Child Inheritance** | `FamilyLogic.getParents()` |
| **Inheritance Source** | `FamilyLogic.getParents()` + `RomanceLogic.getPrimaryPartner()` |
