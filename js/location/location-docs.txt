## 3. RECURSION GUARDS

All modules implement recursion guards to prevent infinite loops:

| GUARD NAME | LOCATION | PURPOSE |
|------------|----------|---------|
| `_processingCommand` | location-commands.js | Prevent command re-entry |
| `_processingQuery` | location-queries.js | Prevent query re-entry |
| `_processingHierarchy` | location-hierarchy.js | Prevent hierarchy re-entry |
| `_processingMovement` | location-movement.js | Prevent movement re-entry |
| `_rendering` | location-ui-list.js | Prevent rendering re-entry |
| `_openingModal` | All modals files | Prevent modal re-entry |
| `_initializingState` | location-state.js | Prevent state re-initialization |
| `_notifyingSubscribers` | location-state.js | Prevent subscriber re-entry |


## 4. ICON POLICY

All icons must come from icons.js via the `_getIcon()` function:

| RULE | DESCRIPTION |
|------|-------------|
| RULE 1 | NO emojis in code or UI |
| RULE 2 | All icons from icons.js via `_getIcon()` |
| RULE 3 | NO icons in confirm/cancel buttons (plain text only) |

**AVAILABLE ICONS USED BY LOCATION SYSTEM:**

| CATEGORY | ICONS |
|----------|-------|
| Basic Shapes | CIRCLE, CIRCLE_DOT |
| UI Elements | LOCATION, HOME, PERSON, SEARCH |
| Status | SUCCESS, WARNING, DANGER |


## 5. DATA STRUCTURES

### Place Object
```javascript
{
    id: string,                    // Unique place ID
    displayName: string,           // Display name
    typeId: string,                // Location type ID
    parentId: string,              // Parent place ID (null if root)
    variableKey: string,           // Internal reference key
    status: string,                // 'active', 'disputed', 'abandoned', 'ruined'
    isCapital: boolean,            // Whether this is a capital
    notes: string,                 // Additional notes
    governmentTypeId: string,      // Government type ID
    governmentStyle: string,       // Government style
    leaderId: string,              // Current leader ID
    leaderAssignments: [],         // Array of leader assignment objects
    settlementData: Object,        // Settlement data
    createdAt: number,             // Timestamp created
    updatedAt: number              // Timestamp updated
}
```

### Location Type Object
```javascript
{
    id: string,                    // Unique type ID
    displayName: string,           // Display name
    priority: number,              // 1-5 (1 = highest)
    icon: string,                  // Icon symbol
    description: string            // Optional description
}
```

### Move Object
```javascript
{
    year: number,                  // Year of move
    locationId: string,            // Destination location ID
    locationName: string,          // Destination location name
    note: string,                  // Optional note
    fromLocationId: string,        // Origin location ID
    fromLocationName: string,      // Origin location name
    isBirthMove: boolean,          // Whether this is a birth record
    timestamp: number              // When recorded
}
```

### Leader Assignment Object
```javascript
{
    id: string,                    // Unique assignment ID
    characterId: string,           // Character ID
    characterName: string,         // Character name
    startYear: number,             // Year started
    endYear: number,               // Year ended (null if active)
    title: string,                 // Leader title
    isActive: boolean,             // Whether currently active
    notes: string,                 // Additional notes
    timestamp: number              // When created
}
```
