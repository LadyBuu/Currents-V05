# 1. SYSTEM OVERVIEW

## Purpose

The Location & Movement System manages the entire geographical hierarchy of the game world, including:
- Location hierarchy (countries, regions, counties, towns, etc.)
- Location types with priority-based sorting
- Character movement and move history
- Population tracking by location
- Location-based analytics and statistics
- Role and apprenticeship integration at locations

## Key Principles

| Principle | Description |
|-----------|-------------|
| **Single Source of Truth** | `location-state.js` holds all location data |
| **Command-Query Separation** | Commands (writes) vs Queries (reads) separated |
| **Separation of Concerns** | State, commands, queries, hierarchy, movement, UI all separate |
| **Recursion Guards** | All public functions protected from infinite loops |
| **Change Notifications** | Subscriptions for reactive updates |
| **No Emojis** | All icons from `icons.js` via `_getIcon()` |
| **Caching** | Performance optimization for all location queries |
| **Priority-Based Hierarchy** | Location types have priorities (1-5) for hierarchy resolution |
| **Role Integration** | Locations track professions and apprenticeships |

# 3. LOCATION-STATE.JS

## Purpose

Single source of truth for all location data. Manages caching, subscriptions, and UI state.

## Dependencies

| Module | Functions Used |
|--------|----------------|
| `accessors.js` | `getPlaces`, `getPlaceById`, `getCharacters`, `getCharacterById`, `getLocationTypes`, `getLocationTypeById` |
| `storage.js` | `saveMasterData` |

## Data Structures

### Place Object
```javascript
{
    id: string,                    // Unique place ID
    displayName: string,           // Display name
    typeId: string,                // Location type ID
    parentId: string,              // Parent place ID (null if root)
    variableKey: string,           // Internal reference key
    status: string,                // 'active', 'disputed', 'abandoned', 'ruined'
    isCapital: boolean,            // Whether this is a capital
    notes: string,                 // Additional notes
    governmentTypeId: string,      // Government type ID
    governmentStyle: string,       // Government style
    leaderId: string,              // Current leader ID
    leaderAssignments: [],         // Array of leader assignment objects
    settlementData: Object,        // Settlement data
    createdAt: number,             // Timestamp created
    updatedAt: number              // Timestamp updated
}
```

### Location Type Object
```javascript
{
    id: string,                    // Unique type ID
    displayName: string,           // Display name
    priority: number,              // 1-5 (1 = highest)
    icon: string,                  // Icon symbol
    description: string            // Optional description
}
```

### Move Object
```javascript
{
    year: number,                  // Year of move
    locationId: string,            // Destination location ID
    locationName: string,          // Destination location name
    note: string,                  // Optional note
    fromLocationId: string,        // Origin location ID
    fromLocationName: string,      // Origin location name
    isBirthMove: boolean,          // Whether this is a birth record
    timestamp: number              // When recorded
}
```

### Leader Assignment Object
```javascript
{
    id: string,                    // Unique assignment ID
    characterId: string,           // Character ID
    characterName: string,         // Character name
    startYear: number,             // Year started
    endYear: number,               // Year ended (null if active)
    title: string,                 // Leader title
    isActive: boolean,             // Whether currently active
    notes: string,                 // Additional notes
    timestamp: number              // When created
}
```

# 11. DATA STRUCTURES

## Place Object

```javascript
{
    id: string,                    // Unique place ID
    displayName: string,           // Display name
    typeId: string,                // Location type ID
    parentId: string,              // Parent place ID (null if root)
    variableKey: string,           // Internal reference key
    status: string,                // 'active', 'disputed', 'abandoned', 'ruined'
    isCapital: boolean,            // Whether this is a capital
    notes: string,                 // Additional notes
    governmentTypeId: string,      // Government type ID
    governmentStyle: string,       // Government style
    leaderId: string,              // Current leader ID
    leaderAssignments: [],         // Array of leader assignment objects
    settlementData: Object,        // Settlement data
    createdAt: number,             // Timestamp created
    updatedAt: number              // Timestamp updated
}
```

## Location Type Object

```javascript
{
    id: string,                    // Unique type ID
    displayName: string,           // Display name
    priority: number,              // 1-5 (1 = highest)
    icon: string,                  // Icon symbol
    description: string            // Optional description
}
```

## Move Object

```javascript
{
    year: number,                  // Year of move
    locationId: string,            // Destination location ID
    locationName: string,          // Destination location name
    note: string,                  // Optional note
    fromLocationId: string,        // Origin location ID
    fromLocationName: string,      // Origin location name
    isBirthMove: boolean,          // Whether this is a birth record
    timestamp: number              // When recorded
}
```

## Leader Assignment Object

```javascript
{
    id: string,                    // Unique assignment ID
    characterId: string,           // Character ID
    characterName: string,         // Character name
    startYear: number,             // Year started
    endYear: number,               // Year ended (null if active)
    title: string,                 // Leader title
    isActive: boolean,             // Whether currently active
    notes: string,                 // Additional notes
    timestamp: number              // When created
}
```

# 14. ICON POLICY

All icons must come from `icons.js` via the `_getIcon()` function:

| Rule | Description |
|------|-------------|
| **Rule 1** | NO emojis in code or UI |
| **Rule 2** | All icons from icons.js via `_getIcon()` |
| **Rule 3** | NO icons in confirm/cancel buttons (plain text only) |

| Home/Settlement | `HOME` |
