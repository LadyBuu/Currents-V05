# 1. NAME SYSTEM OVERVIEW

## Purpose

The Name System manages all name-related operations in the Still Waters simulation, including:
- Random name/surname generation by country/culture
- Family surname inheritance (father/mother/both)
- Patronymic/Matronymic surname generation
- Chain surname generation from multiple generations
- Surname history tracking with undo capability
- Marriage surname changes
- Location-based cultural rules
- Name list management

## Key Principles

| Principle | Description |
|-----------|-------------|
| **Single Source of Truth** | `name-state.js` holds all name data |
| **Command-Query Separation** | Commands (writes) vs Queries (reads) separated |
| **Separation of Concerns** | State, commands, queries, rules, UI all separate |
| **Recursion Guards** | All public functions protected from infinite loops |
| **Change Notifications** | Subscriptions for reactive updates |
| **No Emojis** | All icons from `icons.js` via `_getIcon()` |
| **Caching** | Performance optimization for random names and history |

---

## Directory Structure

```
js/core/
├── name-state.js           # Single source of truth + cache + notifications
├── name-commands.js        # All write operations (surname changes, name lists)
├── name-queries.js         # All read operations (generation, lookup, history)
├── name-rules.js           # Business logic for name generation rules
├── modals-name.js          # UI modals (generator, surname management)
└── name-system.js          # Legacy wrapper (backward compatibility)

js/core/name-docs.txt       # This documentation
```

**DEPENDENCIES:**

## State Structure

```javascript
_state = {
    nameLists: {},              // Raw name lists by country
    surnameHistories: new Map(), // Surname histories by character ID
    cache: {
        countryNameLists: new Map(),
        characterSurnameHistory: new Map(),
        randomNames: new Map(),
        randomSurnames: new Map()
    },
    subscribers: [],            // Change listeners
    uiState: {
        selectedCountry: null,
        selectedGender: 'male',
        previewName: '',
        previewSurname: '',
        generationMode: 'random',
        filters: { gender: 'all', minAge: null, maxAge: null }
    },
    initialized: false
};
```

# 5. NAME-RULES.JS

**PURPOSE:** Business logic for name generation rules.

**DEPENDENCIES:**
- `name-queries.js` - `NameQueries`

---

## Rule Types

```javascript
RULE_TYPES = {
    RANDOM: 'random',           // Random name from cultural pool
    FAMILY: 'family',           // Surname derived from parents
    PATRONYMIC: 'patronymic',   // Surname derived from parent (with prefix/suffix)
    CHAIN: 'chain',             // Surname from multiple generations
    HYPHENATED: 'hyphenated',   // Surname combining both parents with hyphen
    CUSTOM: 'custom'            // Custom rule logic
}
```

---

## Rule Presets

| Preset | Description | Rules |
|--------|-------------|-------|
| `european` | Father's surname only | `family: { source: 'father', count: 1 }` |
| `spanish` | Father's surname + Mother's surname | `family: { source: 'both', count: 2 }` |
| `icelandic` | Patronymic: son/dottir suffix | `patronymic: { source: 'father', maleSuffix: 'son', femaleSuffix: 'dottir' }` |
| `russian` | Patronymic: ovich/ovna suffix | `patronymic: { source: 'father', maleSuffix: 'ovich', femaleSuffix: 'ovna' }` |
| `arabic` | Chain: ibn/bin/bint from father/grandfather | `chain: { order: ['father', 'paternal_grandfather'], depth: 2 }` |
| `hyphenated` | Hyphenated: father-mother | `family: { source: 'both', connector: 'hyphen' }` |

# 10. ICON POLICY

All icons must come from `icons.js` via the `_getIcon()` function:

| Rule | Description |
|------|-------------|
| **Rule 1** | NO emojis in code or UI |
| **Rule 2** | All icons from icons.js via `_getIcon()` |
| **Rule 3** | NO icons in confirm/cancel buttons (plain text only) |

| Location | `LOCATION` |

// Get a random name
var name = NameQueries.getRandomName('country_1', 'male');

// Get a random surname
var surname = NameQueries.getRandomSurname('country_1');
console.log('Random surname:', surname);

// Generate family surname
var father = { surname: 'Smith' };
var mother = { surname: 'Jones' };
var familyName = NameQueries.generateFamilySurname(father, mother, {
    source: 'both',
    connector: 'hyphen',
    count: 2
});
console.log('Family surname:', familyName); // "Smith-Jones"

// Generate patronymic
var father = { name: 'John' };
var patronymic = NameQueries.generatePatronymicSurname(father, 'male', {
    maleSuffix: 'son',
    useSuffix: true
});
console.log('Patronymic:', patronymic); // "Johnson"

// Get surname history
var history = NameQueries.getSurnameHistory('char_123');
console.log('Surname history:', history);

var result = NameCommands.recordSurnameChange(character, 'Smith-Jones', 1250, 'marriage');

openNameGeneratorModal({

    }
});
