# 1. SYSTEM OVERVIEW

## Purpose

The Role System manages all role/profession definitions and assignments in the Still Waters simulation. It provides:

- Role CRUD operations (Create, Read, Update, Delete)
- Category management for organizing roles
- Role assignment to characters with skill levels
- Skill management (tracking and updating)
- Integration with Apprenticeship System for teaching thresholds
- UI rendering for role lists, detail panels, and cards

## Key Principles

| Principle | Description |
|-----------|-------------|
| **Single Source of Truth** | `role-state.js` holds all role data and caching |
| **Command-Query Separation** | Commands (writes) vs Queries (reads) separated |
| **Separation of Concerns** | State, commands, queries, UI, constants all separate |
| **Recursion Guards** | All public functions protected from infinite loops |
| **Change Notifications** | Subscriptions for reactive updates |
| **No UI in Data Layer** | UI rendering isolated in `role-ui-list.js` and `modals-roles.js` |
| **No Emojis in UI** | All icons from `icons.js` via `_getIcon()` |

# 2. FILE STRUCTURE

```
js/core/role/
├── role-constants.js       # Pure constants (no dependencies)
├── role-state.js           # Single source of truth + cache + notifications
├── role-commands.js        # All write operations (CRUD, assignment, categories)
├── role-queries.js         # All read operations (queries, statistics)

├── role-system.js          # Wrapper / re-exporter for backward compatibility
```

## Migration Path for Existing Code

### 1. Update Global State Access

```javascript
// Old
var state = window.roleSystemState;
var selected = state.selectedRoleId;

// New
var uiState = RoleState.getUIState();
var selected = uiState.selectedRoleId;
```

### 2. Update Role Creation

```javascript
// Old
window.addNewRole(function(roleId) {
    console.log('Created:', roleId);
});

// New
window.createRole({ name: 'Blacksmith' });
// OR
window.openCreateRoleModal(function(roleId) {
    console.log('Created:', roleId);
});
```

### 3. Update Role Deletion

```javascript
// Old
window.deleteRoleWithConfirm(roleId, function() {
    console.log('Deleted');
});

// New
window.deleteRole(roleId, true);
// OR
window.openDeleteRoleModal(roleId, function() {
    console.log('Deleted');
});
```

### 4. Update Detail Panel Rendering

```javascript
// Old
window.renderRoleDetailTab('container', roleId, onBack, onRefresh);

// New
RoleUI.renderRoleDetailPanel('container', roleId, onBack, onRefresh);
```

