# COMPLETE ROLE SYSTEM DOCUMENTATION

## SYSTEM OVERVIEW

The Role System manages all professions, occupations, and positions that characters can hold in the game world. It provides a complete API for role CRUD operations, category management, role assignment to characters, skill tracking, salary management, and literacy requirements.

**Key Design Principles:**
- **Single Source of Truth**: `role-state.js` holds all role data
- **Command-Query Separation**: Commands (writes) vs Queries (reads) separated
- **Separation of Concerns**: State, commands, queries, UI all separate
- **Recursion Guards**: All public functions protected from infinite loops
- **Category Organization**: Roles organized by categories for filtering
- **Skill Tracking**: Each character has a skill level (0-100) for each role
- **Salary System**: Roles have base salaries with category defaults
- **Literacy Requirements**: Roles can require specific literacy levels
- **Gender Restrictions**: Roles can be restricted by gender
- **Specializations**: Roles can have specializations for detailed tracking
- **UI Integration**: Dedicated role selector modals for cross-system use

---

## FILE STRUCTURE

```
js/systems/roles/
├── role-state.js              # Single source of truth + cache + notifications
├── role-commands.js           # All write operations (CRUD, assignment, skill updates)
├── role-queries.js            # All read operations (search, filter, stats)
├── role-constants.js          # All constants (categories, salary defaults, literacy levels)
├── role-system.js             # Wrapper for backward compatibility
├── role-ui-list.js            # UI rendering for roles (lists, cards, detail panels)
├── modals-roles.js            # UI modals (create, edit, assign, delete, etc.)
└── modals-role-select.js      # Reusable role selector modals
```
