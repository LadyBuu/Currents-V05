1.2 apprenticeship-state.js - State Layer
-----------------------------------------

PURPOSE: Single source of truth for apprenticeship data.

DEPENDENCIES:
  - accessors.js (getCharacterById, getCharacters)
  - relationship-registry.js (getAllRelationships, getRelationshipBetween)
  - storage.js (saveMasterData)

STATE STRUCTURE:

_state = {
    apprenticeships: [],           // All apprenticeship relationships
    cache: {
        byMaster: Map<string, Array>,    // Master ID → Apprenticeships
        byApprentice: Map<string, Array>, // Apprentice ID → Apprenticeships
        byRole: Map<string, Array>       // Role ID → Apprenticeships
    },
    uiState: {
        selectedMasterId: string | null,
        selectedApprenticeId: string | null,
        filters: {
            role: string | null,
            status: 'ongoing' | 'all'
        }
    },
    subscribers: Array<Function>,
    lastUpdated: number | null,
    _initialized: boolean
};

4. RECURSION GUARDS
================================================================================

All modules implement recursion guards to prevent infinite loops:

┌─────────────────────────────────────────────────────────────────────────────┐
│ GUARD NAME              │ LOCATION                     │ PURPOSE          │
├─────────────────────────┼─────────────────────────────┼───────────────────┤
│ _processingStateUpdate  │ apprenticeship-state.js     │ Prevent state    │
│                         │ role-state.js               │ notification     │
│                         │                             │ re-entry         │
├─────────────────────────┼─────────────────────────────┼───────────────────┤
│ _processingCommand      │ apprenticeship-commands.js  │ Prevent command  │
│                         │ role-commands.js            │ re-entry         │
├─────────────────────────┼─────────────────────────────┼───────────────────┤
│ _processingQuery        │ apprenticeship-queries.js   │ Prevent query    │
│                         │ role-queries.js             │ re-entry         │
├─────────────────────────┼─────────────────────────────┼───────────────────┤
│ _processingLearning     │ apprenticeship-learning.js  │ Prevent learning │
│                         │                             │ re-entry         │
├─────────────────────────┼─────────────────────────────┼───────────────────┤
│ _processingModal        │ modals-apprenticeship.js    │ Prevent modal    │
│                         │ modals-roles.js             │ re-entry         │
└─────────────────────────┴─────────────────────────────┴───────────────────┘

Example usage pattern:

```javascript
var _processingCommand = false;

function someCommand() {
    if (_processingCommand) {
        return null;
    }
    _processingCommand = true;

    try {
        // ... command logic ...
        return result;
    } finally {
        _processingCommand = false;
    }
}
```
