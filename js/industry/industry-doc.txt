# Industry & Enterprise System

**Location:** `js/core/industry/`
**Version:** 3.0
**Updated:** 2026-10-22

---

## 1. Ownership Contract

The industry domain owns four classes of record and one cross-domain
relationship. Everything else it consumes.

### Owns

| Record | Stored in | Owner module | Authority |
|---|---|---|---|
| Enterprise | `masterData.data.enterprises[]` | `IndustryCommands` | sole writer |
| Enterprise type | `masterData.data.enterpriseTypes[]` | `IndustryTypeCommands` | sole writer |
| Enterprise in-memory catalogue | `IndustryState` | `IndustryState` | sole writer (via `_` primitives) |
| Enterprise type in-memory catalogue | `IndustryState` | `IndustryState` | sole writer (via `_` primitives) |

### Consumes (read-only)

| Data | Via | Notes |
|---|---|---|
| Character record | `getCharacterById` | owner lookup, worker lookup |
| Household record | `getHouseholdById` | owner lookup, cross-domain write routing |
| Place record | `getPlaceById` | location lookup, settlement/state owner lookup |
| Current year | `getCurrentYear` | founded year, processing year |
| ID generation | `generateId` | new enterprise, new type |
| Persistence | `saveMasterData`, `markDataDirty` | commands own persistence |

### Cross-domain writes

| Effect | Routed through | Notes |
|---|---|---|
| Add enterprise to household reverse-index | `HouseholdCommands.addEnterpriseToHousehold` | when `ownerType === 'household'` on create |
| Remove enterprise from household reverse-index | `HouseholdCommands.removeEnterpriseFromHousehold` | on delete, demolish |
| Adjust household wealth | `HouseholdCommands.updateHousehold(householdId, { wealth })` | annual processing household transfer |

Industry NEVER writes to household records, character records, or place records directly. The household reverse-index (`household.enterprises[]`) is the only household-owned field industry mutates, and it is done via `HouseholdCommands`, never by reaching into the record.

## 2. Load Order

Every script tag in an HTML file that uses the industry domain must appear in this order. The bootstrap's load-time verification refuses to run if any required module is missing.

```html
<!-- Core -->
<script src="js/core/time.js"></script>
<script src="js/core/ids.js"></script>
<script src="js/core/storage.js"></script>
<script src="js/core/accessors.js"></script>
<script src="js/core/icons.js"></script>
<script src="js/core/formatting.js"></script>
<script src="js/core/modals-core.js"></script>

<!-- Cross-domain (before industry) -->
<script src="js/core/character/character-commands.js"></script>
<script src="js/systems/household/household-commands.js"></script>

<!-- Industry (this exact order) -->
<script src="js/core/industry/industry-constants.js"></script>
