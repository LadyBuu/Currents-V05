# 1. SYSTEM OVERVIEW

## Purpose

The Industry & Enterprise System manages all economic enterprises in the game world, including farms, workshops, factories, mines, and commercial establishments. It provides:

- **Enterprise Management** - Create, update, delete, and track enterprises
- **Enterprise Types** - Registry of enterprise types with base stats
- **Worker Management** - Hire, fire, and manage workers with individual wages
- **Annual Processing** - Calculate income, expenses, wages, and profits
- **Ownership Tracking** - Enterprises can be owned by characters, households, or settlements (public)
- **Public Enterprises** - Settlement-owned enterprises that generate public revenue
- **Financial History** - Track wealth, debt, and profit over time

## Key Principles

| Principle | Description |
|-----------|-------------|
| **Single Source of Truth** | `industry-state.js` holds all enterprise data |
| **Command-Query Separation** | Commands (writes) vs Queries (reads) separated |
| **Separation of Concerns** | State, commands, queries, types, processor, UI all separate |
| **Recursion Guards** | All public functions protected from infinite loops |
| **Change Notifications** | Subscriptions for reactive updates |
| **No Emojis** | All icons from `icons.js` via `_getIcon()` |
| **Public Enterprise Support** | Enterprises can be publicly owned by settlements |
| **Integration Ready** | Public enterprises integrate with Settlement System |

## Internal State Structure

```javascript
_state = {
    enterprises: [],                // All enterprises
    enterpriseTypes: [],            // Enterprise type definitions
    cache: {
        byId: new Map(),            // Enterprise ID lookup
        byOwner: new Map(),         // Owner ID lookup
        byLocation: new Map(),      // Location ID lookup
        byStatus: new Map(),        // Status lookup
        byType: new Map(),          // Type lookup
        byOwnershipType: new Map(), // Public/Private lookup (NEW)
        summary: new Map()          // Enterprise summary cache
    },
    subscribers: [],                // Change listeners
    _processingState: false,        // Recursion guard
    _initialized: false
};
```

## Functions

#### `IndustryProcessor.processAnnualEnterprise(enterpriseId)`

| Property | Value |
|----------|-------|
| **Description** | Processes a single enterprise's annual finances |
| **Parameters** | `enterpriseId` (string) - Enterprise ID |
| **Returns** | `Object` - Processing results |

**Processing Steps:**
1. Calculate annual income
2. Calculate total wages
3. Calculate annual expenses (expenses + wages)
4. Calculate net profit (income - expenses)
5. Calculate total profit (net profit * years)
6. Update wealth with total profit
7. Apply debt interest (5% annually)
8. Mark bankrupt if wealth < -100
9. Update lastProcessedYear

**Return Object:**
