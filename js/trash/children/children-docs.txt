# CHILDREN & FAMILY SYSTEM - COMPLETE DOCUMENTATION

## SYSTEM OVERVIEW

The Children & Family System manages all aspects of family relationships, including birth, adoption, surrogacy, pregnancy, and family lineage tracking. It provides a complete API for recording births, managing adoptions, creating surrogacy arrangements, and tracking family relationships across generations.

**Key Design Principles:**
- **Single Source of Truth**: `children-state.js` holds all child-related data
- **Command-Query Separation**: Commands (writes) vs Queries (reads) separated
- **Separation of Concerns**: State, commands, queries, lifecycle, UI all separate
- **Recursion Guards**: All public functions protected from infinite loops
- **Household Integration**: Children can be assigned to households
- **Character Integration**: Children are full character objects with parent relationships
- **Adoption Tracking**: Legal, guardianship, and foster care relationships
- **Surrogacy Management**: Full surrogacy arrangement lifecycle
- **Pregnancy History**: Historical pregnancy tracking
- **Inheritance Support**: Legitimization and inheritance rights

---

## FILE STRUCTURE

```
js/core/children/
├── children-state.js              # Single source of truth + cache + notifications
├── children-commands.js           # All write operations (birth, adoption, surrogacy)
├── children-queries.js            # All read operations (adoption, pregnancy, surrogacy)
├── children-lifecycle.js          # Business logic (fertility, pregnancy, inheritance)
├── pregnancy-service.js           # Pure pregnancy logic (fertility, complications)
├── surrogacy-service.js           # Pure surrogacy logic
├── adoption-service.js            # Pure adoption logic
└── modals-*.js                    # UI modals (birth, adoption, surrogacy)

js/core/modals/
├── modals-adoption.js                 # Adoption modals
├── modals-birth.js                    # Birth modals
└── modals-surrogacy.js                # Surrogacy modals
```

## Data Schemas

### Adoption Record Schema

| Field | Type | Description |
|-------|------|-------------|
| `parentId` | string | Adoptive parent character ID |
| `parentName` | string | Parent name |
| `year` | number | Year of adoption |
| `type` | string | 'legal', 'guardianship', 'foster' |
| `notes` | string | Notes |
| `status` | string | 'active', 'ended', 'dissolved' |
| `timestamp` | number | Creation timestamp |

### Pregnancy Record Schema

| Field | Type | Description |
|-------|------|-------------|
| `motherId` | string | Mother character ID |
| `fatherId` | string | Father character ID |
| `childId` | string | Child character ID |
| `childIds` | array | Child IDs (for multiple) |
| `birthYear` | number | Year of birth |
| `gender` | string | 'male', 'female', 'mixed' |
| `isMultiple` | boolean | Multiple birth flag |
| `fetusCount` | number | Number of fetuses |
| `isStillborn` | boolean | Stillborn flag |
| `hasComplications` | boolean | Complications flag |
| `maternalDeath` | boolean | Maternal death flag |
| `notes` | string | Notes |

### Surrogacy Record Schema

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique identifier |
| `intendedParentId` | string | Intended parent ID |
| `intendedPartnerId` | string | Co-parent ID |
| `surrogateId` | string | Surrogate character ID |
| `spermDonorId` | string | Sperm donor ID |
| `eggDonorId` | string | Egg donor ID |
| `arrangementYear` | number | Year arranged |
| `expectedBirthYear` | number | Expected birth year |
| `actualBirthYear` | number | Actual birth year |
| `childIds` | array | Children born |
| `status` | string | 'active', 'completed', 'cancelled' |
| `type` | string | 'traditional' or 'gestational' |
| `notes` | string | Notes |
