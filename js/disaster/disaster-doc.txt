# COMPLETE DISASTER SYSTEM DOCUMENTATION

## SYSTEM OVERVIEW

The Disaster System manages all catastrophic events in the game world, including natural disasters (earthquakes, floods, fires, hurricanes, etc.) and societal crises (plagues, famines). It provides comprehensive disaster generation, effect application (including structural damage to settlements, education, industry, residences, and households), statistical tracking, and UI components.

**Key Design Principles:**
- **Single Source of Truth**: `disaster-state.js` holds all disaster data
- **Command-Query Separation**: Commands (writes) vs Queries (reads) separated
- **Separation of Concerns**: State, commands, queries, constants, UI all separate
- **Recursion Guards**: All public functions protected from infinite loops
- **Change Notifications**: Subscriptions for reactive updates
- **No Emojis**: All icons from `icons.js` via `_getIcon()`
- **Location Modifiers**: Terrain keywords affect disaster severity
- **Comprehensive Damage**: Affects settlement features, schools, enterprises, residences, households
- **Damage Coordinator**: Centralized structural damage application across systems

## DISASTER-STATE.JS

**PURPOSE:** Single source of truth for all disaster data. Manages caching, subscriptions, and data persistence.

### Query Functions

| Function | Parameters | Returns | Description |
|----------|------------|---------|-------------|
| `DisasterState.getDisaster(disasterId)` | `disasterId` (string) | `Object\|null` | Gets a single disaster by ID |
| `DisasterState.getAllDisasters()` | None | `Array` | Gets all disasters |
| `DisasterState.getDisastersByLocation(locationId)` | `locationId` (string) | `Array` | Gets disasters by location |
| `DisasterState.getDisastersInYearRange(startYear, endYear)` | `startYear`, `endYear` | `Array` | Gets disasters in year range |
| `DisasterState.getDisasterCount()` | None | `number` | Gets total number of disasters |
| `DisasterState.getDisasterTypeCount(disasterId)` | `disasterId` (string) | `number` | Gets count by type |

| Function | Parameters | Returns | Description |
|----------|------------|---------|-------------|

| `DisasterState.deleteDisaster(disasterId)` | `disasterId` (string) | `Object` | Deletes a disaster |

### Subscription

| Function | Parameters | Returns | Description |
|----------|------------|---------|-------------|
| `DisasterState.subscribe(callback)` | `callback` (function) | `function` | Subscribes to state changes |

### Cache Management

| Function | Parameters | Returns | Description |
|----------|------------|---------|-------------|
| `DisasterState.invalidateCache()` | None | None | Invalidates all caches and rebuilds from masterData |

## DISASTER-DAMAGE.JS (NEW)

**PURPOSE:** Central coordinator for applying structural damage from disasters. Integrates with Settlement, Education, Industry, Household, and Residence systems.

### Core Damage Calculation

| Function | Parameters | Returns | Description |
|----------|------------|---------|-------------|
| `DisasterDamage.applyStructuralDamage(locationId, disaster, options)` | `locationId`, `disaster`, `options` | `Object` | Main entry point: Applies structural damage from a disaster |
| `DisasterDamage.getDamageSummary(disasterId)` | `disasterId` (string) | `Object\|null` | Gets damage summary for a disaster |
| `DisasterDamage.getDestructionList(disasterId, type)` | `disasterId`, `type` | `Array\|null` | Gets all destruction caused by a disaster |
| `DisasterDamage.getLocationDestruction(locationId, options)` | `locationId`, `options` | `Array` | Gets all destroyed items for a location |

### Damage Results Structure

```javascript
{
    success: true,
    locationId: string,
    disasterId: string,
    year: number,
    featuresDestroyed: [{ id, name, type, category, demolished, year }],
    schoolsDestroyed: [{ id, name, type, institutionType, demolished, year }],
    enterprisesDestroyed: [{ id, name, type, category, demolished, year }],
    residencesDemolished: [{ id, name, type, residenceType, unitsDemolished, demolished, year }],
    householdsDestroyed: [{ id, name, type, membersRemoved, demolished, year }],
    totalLoss: number,
    summary: {
        features: number,
        schools: number,
        enterprises: number,
        residences: number,
        households: number
    },
    errors: [{ system, error }]
}
```

### Destruction Chance Calculation

| Factor | Weight |
|--------|--------|
| Base chance | `severity / 100 * 0.65` (capped at 0.65) |
| Disaster type multiplier | 0.1-1.4 (earthquake: 1.4, plague: 0.1, drought: 0.5, etc.) |
| System-specific multiplier | 0.5-0.9 (households: 0.5, schools: 0.7, residences: 0.9) |

### System Integration Summary

| System | Destroy Function | Called When |
|--------|------------------|-------------|
| Settlement | `demolishFeature()` | Features destroyed |
| Education | `demolishInstitution()` | Schools destroyed |
| Industry | `demolishEnterprise()` | Enterprises destroyed |
| Residence | `demolishResidence()` | Residences demolished |
| Household | `demolishHousehold()` | Households destroyed |

## QUICK TEST COMMANDS

```javascript
// Generate a random disaster
var result = window.DisasterCommands.generateDisaster('loc_123', 1250, null);
console.log('Generated disaster:', result.data);

// Trigger a plague
var plagueResult = window.DisasterCommands.triggerPlague('loc_123', 1250, { applyEffects: true });
console.log('Plague deaths:', plagueResult.data.deaths);
console.log('Prosperity lost:', plagueResult.data.prosperityLoss);

// Get disaster statistics
var stats = window.DisasterQueries.getDisasterStats('loc_123');
console.log('Total disasters:', stats.total);
console.log('Total deaths:', stats.totalDeaths);

// Calculate disaster risk
var risk = window.DisasterQueries.getLocationDisasterRisk('loc_123');
console.log('Risk level:', risk.level);
console.log('Risk score:', risk.score);

// Get destruction statistics (NEW)
var destruction = window.DisasterQueries.getDestructionStatistics('loc_123');
console.log('Total loss:', destruction.totalLoss);
console.log('Features destroyed:', destruction.totalDestructions.features);
console.log('Schools destroyed:', destruction.totalDestructions.schools);

// Apply structural damage (NEW)
var damageResult = window.DisasterDamage.applyStructuralDamage('loc_123', disaster, {
    demolishHouseholds: true
});
console.log('Features destroyed:', damageResult.featuresDestroyed.length);
console.log('Total loss:', damageResult.totalLoss);

// Render stats panel
window.DisasterStatsUI.renderStatsPanel('stats-container', 'loc_123');

// Open create disaster modal
window.DisasterModals.openCreateDisasterModal({
    title: 'Trigger Disaster',
    onComplete: function(disaster) {
        console.log('Disaster created:', disaster);
    }
});

// Simulate random disaster
var randomResult = window.DisasterCommands.simulateRandomDisaster(1250, 0.05);
console.log('Random disaster result:', randomResult);
```
