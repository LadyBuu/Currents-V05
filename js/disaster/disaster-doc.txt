## 1. Ownership contract

The Disaster domain owns exactly one canonical array on `masterData.data`:

| Array | Shape | Owner |
|---|---|---|
| `disasters` | `[{ id, year, disasterType, disasterId, locationId, locationName, severity, deaths, population, prosperityLoss, crimeIncrease, schoolsDestroyed, description, actualDeaths, metadata, createdAt, structuralDamage, featuresDestroyed, enterprisesDestroyed, residencesDemolished, householdsDestroyed, totalLoss }]` | Disaster |

Disaster **does not** own:

| Data | Owner | Read via | Written via |
|---|---|---|---|
| Settlement (prosperity, crime rate, features, civil laws) | Settlement | `SettlementQueries.getSettlementData`, `SettlementFeatureQueries.getFeatureById` | `modifySettlementProsperity`, `modifySettlementCrimeRate`, `SettlementFeatureCommands.demolishFeature` |
| Character identity and death | Character | `getCharacterById`, `getCharacters`, `getCurrentLocation` | `killCharacter` |
| Household membership, wealth, residence link | Household | `HouseholdState.getHouseholdsByLocation` | `HouseholdCommands.demolishHousehold` |
| Places and locations | Location | `getPlaceById`, `getPlaces`, `getAllSubLocationIds`, `getLocationPopulationCount` | — |
| Educational institutions | Education | `EducationState.getInstitutionsByLocation` | `EducationCommands.demolishInstitution` |
| Enterprises | Industry | `IndustryState.getEnterprisesByLocation` | `IndustryCommands.demolishEnterprise` |
| Residences | Residence | `ResidenceSystem.getResidencesByLocation` | `ResidenceSystem.demolishResidence` |

Cross-domain **writes** go through the owning domain's commands. Cross-domain **reads** go through the owning domain's queries or state reads for the reads the domain exposes publicly. Disaster code never writes into another domain's canonical arrays.
