# EDUCATION SYSTEM - COMPLETE DOCUMENTATION

## SYSTEM OVERVIEW

The Education System manages all educational institutions, student enrollment, teacher management, learning progression, and institutional administration within the game world. It provides a complete API for institution CRUD operations, student/teacher management, headmaster appointments, curriculum management, and settlement budget integration.

**Key Design Principles:**
- **Single Source of Truth**: `education-state.js` holds all education data
- **Command-Query Separation**: Commands (writes) vs Queries (reads) separated
- **Separation of Concerns**: State, commands, queries, learning, annual processing, UI all separate
- **Recursion Guards**: All public functions protected from infinite loops
- **Role Integration**: Institutions can teach specific roles (professions)
- **Settlement Integration**: Public schools receive funding from settlement budgets
- **Private School Economy**: Private schools charge tuition and generate profit for owners
- **Religious School System**: Schools owned by religions with doctrine teaching and clergy oversight
- **Tuition System**: Dynamic tuition based on reputation, type, and manual overrides
- **Specialization**: Institutions can specialize in specific role categories
- **Graduation with Role Granting**: Graduates can receive roles upon completion
- **History Tracking**: Full historical record of all institution events

## FILE STRUCTURE

```
js/systems/education/
├── education-state.js              # Single source of truth + cache + notifications
├── education-commands.js           # All write operations (CRUD, enrollment, hiring, graduation)
├── education-queries.js            # All read operations (search, filter, stats, demand)
├── education-learning.js           # Core learning mechanics (proficiency, literacy, advancement)
├── education-annual.js             # Annual processing (learning, graduation, finances, budgets)
├── education-history.js            # History tracking (teacher, student, headmaster events)
├── education-constants.js          # All constants (levels, subjects, institution types, ownership types)
├── education-system.js             # Wrapper for backward compatibility
└── modals-education.js             # UI modals

js/core/modals/
├── modals-education.js                 # Main education modals
├── modals-char-select.js               # Character selector
└── modals-household-selector.js        # Household selector
```

# 15. TYPES OF EDUCATIONAL INSTITUTIONS

| Ownership Type | Tuition | Funding | Owner | Use Case |
|----------------|---------|---------|-------|----------|
| **Public** | Free (0 gold) | Government/settlement | None | Standard education for all |
| **Private** | Tuition-based | Tuition fees | Character or Household | Elite/noble education, profit-driven |
| **Religious** | Free or discounted | Religion/Settlement subsidies | Religion | Clergy training, doctrinal education |
