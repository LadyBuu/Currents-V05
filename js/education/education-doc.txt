# EDUCATION SYSTEM - COMPLETE DOCUMENTATION

## SYSTEM OVERVIEW

The Education System manages educational institutions where characters can study, learn subjects, and graduate with professions. Schools can be specialized in specific role categories (Medical, Combat, Industrial, etc.) and grant specific roles to graduates.

---

## DIRECTORY STRUCTURE

Based on your project structure, the Education System files are located at:

```
js/education/
├── education-constants.js        # All constants (institution types, subjects, categories)
├── education-state.js            # Single source of truth + cache + notifications
├── education-commands.js         # All write operations (CRUD, enrollment, graduation, hiring)
├── education-queries.js          # All read operations (search, filter, stats, role-based queries)
├── education-learning.js         # Learning mechanics (proficiency, literacy, skill advancement)
├── education-annual.js           # Annual processing (auto-learning, graduation readiness, finances)
├── education-history.js          # Historical record keeping (teacher/student/headmaster history)
├── education-system.js           # Wrapper re-exporting all functions (backward compatibility)
├── modals-education.js           # UI modals (CRUD, enrollment, graduation, hiring)
└── education-doc.txt             # This documentation
```

## KEY PRINCIPLES

| Principle | Description |
|-----------|-------------|
| **Single Source of Truth** | `education-state.js` holds all education data |
| **Command-Query Separation** | Commands (writes) vs Queries (reads) separated |
| **Separation of Concerns** | State, commands, queries, UI all separate |
| **Recursion Guards** | All public functions protected from infinite loops |
| **Change Notifications** | Subscriptions for reactive updates |
| **No Emojis** | All icons from `icons.js` via `_getIcon()` |
| **No Teacher Skill** | Teachers are hired based on profession, not skill level |
| **No Auto-Role on Graduation** | Graduation grants roles but does not auto-add professions without user selection |
| **Literacy Not Enforced** | Manual override available for literacy tracking |

# 13. INTEGRATION WITH ROLE SYSTEM

## Integration Points

### 1. Role → Education (Curriculum)

Roles can be added to an institution's curriculum as "taught roles".

**Data Flow:**
```
Role System → Education System
Role → institution.taughtRoles[] → institution.curriculum[]
```

### 2. Role → Education (Specialization)

Institutions can be specialized by role category.

**Data Flow:**
```
Role System → Education System
Role.category → institution.specializationCategory
```

### 3. Education → Role (Graduation)

Graduates can be granted roles from the institution's taught roles.

**Data Flow:**
```
Education System → Role System
Education.graduateStudent() → RoleCommands.assignRoleToCharacter()
```

### 4. Role → Education (Teacher Qualification)

Teachers are checked for the profession they teach.

**Data Flow:**
```
Role System → Education System
RoleQueries.getCharactersWithRoleDetails() → Education.hireTeacher()
```
