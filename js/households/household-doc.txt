# HOUSEHOLD & RESIDENCE SYSTEM - COMPLETE DOCUMENTATION

## SYSTEM OVERVIEW

The Household & Residence System manages all household structures, family units, staff, departments, and residence management. It provides a complete API for household CRUD operations, member management, household economy, staff positions, servant relationships, and residence management including units, vacancy, and history.

**Key Design Principles:**
- **Single Source of Truth**: `household-state.js` holds all household data
- **Command-Query Separation**: Commands (writes) vs Queries (reads) separated
- **Separation of Concerns**: State, commands, queries, economy, UI all separate
- **Recursion Guards**: All public functions protected from infinite loops
- **Role Integration**: Positions can require roles (generic professions)
- **Name Period Management**: Full household name history with period tracking
- **Deceased Members**: Remain in household (don't stop being part of the family)
- **History Preservation**: All previous households always stay in history
- **Residence Integration**: Households can be assigned to residences and units
- **Government Integration**: Government salaries flow into household economy; taxes collected
- **Enterprise Integration**: Households can own and manage enterprises

## Constants

### Household Status Values

| Status | Description |
|--------|-------------|
| `active` | Household is active with living members |
| `vacant` | Household has no living members |
| `abandoned` | Household has only deceased members |
| `declining` | Household has few living members |
| `deprecated` | Household is no longer in use |
| `bankrupt` | Household is in financial bankruptcy |
