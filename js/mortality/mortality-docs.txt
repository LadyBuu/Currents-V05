# 1. SYSTEM OVERVIEW

## Purpose

The Death System manages all character mortality events including natural death, murder, execution, and childbirth death. It provides:

- **Death Recording** - Natural, disease, accident, suicide, and other causes
- **Murder Tracking** - With motive, method, and killer tracking
- **Execution Management** - With reason, method, and location tracking
- **Statistics** - Comprehensive mortality analytics
- **UI Modals** - User interfaces for all death operations

## Key Principles

| Principle | Description |
|-----------|-------------|
| **Single Source of Truth** | `mortality-state.js` holds all death data |
| **Command-Query Separation** | Commands (writes) vs Queries (reads) separated |
| **Separation of Concerns** | State, commands, queries, UI all separate |
| **Recursion Guards** | All public functions protected from infinite loops |
| **Change Notifications** | Subscriptions for reactive updates |

# 2. FILE STRUCTURE

```
js/core/mortality/
├── mortality-state.js       # Single source of truth + cache + notifications
├── mortality-commands.js    # All write operations (kill, murder, execution)
```

## Functions

#### `openDeathModal(character, onSuccess)`

| Property | Value |
|----------|-------|
| **Description** | Opens the main death modal for a character |
| **Parameters** | `character` (Object) - Character to kill, `onSuccess` (function) - Callback |
| **Returns** | `void` |

- Select death category (Natural, Disease, Accident, Animal, War, Childbirth, Suicide, Murder, Execution, Other)
- Choose specific cause with suggestions
- Set age at death (auto-calculates year)
- Add notes

|----------|-------|
| **Description** | Opens the murder modal |
| **Parameters** | `victim` (Object) - Victim character, `onSuccess` (function) - Callback |
| **Returns** | `void` |

**Features:**
- Select murderer from character list
- Filter by location
- Choose murder method
- Select motive with suggestions
- Option for killer to escape justice

|----------|-------|

# 13. USAGE EXAMPLES

## Example 1: Natural Death

```javascript
// Get a character
var character = window.getCharacterById('char_123');

// Open death modal
window.openDeathModal(character, function() {
    console.log('Character died');
});

// Or programmatically
window.MortalityCommands.killCharacter(character, 1250, 'Old age', {
    notes: 'Peaceful death'
});
```

## Example 2: Murder

```javascript
// Get victim and killer
var victim = window.getCharacterById('char_123');
var killer = window.getCharacterById('char_456');

// Open murder modal
window.openMurderModal(victim, function() {
    console.log('Murder recorded');
});

// Or programmatically
window.MortalityCommands.recordMurder(victim, killer, 1250, {
    motive: 'Jealousy',
    method: 'Stabbing',
    killerGotAway: false,
    notes: 'Murdered in the night'
});
```

## Example 3: Execution

```javascript
// Get condemned character
var condemned = window.getCharacterById('char_123');

// Open execution modal
window.openExecutionModal(condemned, function() {
    console.log('Execution recorded');
});

// Or programmatically
window.MortalityCommands.recordExecution(condemned, 1250, 'Treason', {
    method: 'beheading',
    location: 'Town square',
    notes: 'Public execution'
});
```

## Example 4: Get Statistics

```javascript
// Get mortality statistics
var stats = window.MortalityQueries.getMortalityStatistics();
console.log('Total deaths:', stats.totalDeaths);
console.log('Murders:', stats.totalMurders);
console.log('Executions:', stats.totalExecutions);

// Get murder statistics
var murderStats = window.MortalityQueries.getMurderStatistics();
console.log('Murders by motive:', murderStats.byMotive);

// Get character relationship summary
var summary = window.MortalityQueries.getCharacterRelationshipSummary(character);
console.log('Relationship status:', summary);
```

## Example 5: Filter Death Records

```javascript
// Get deaths by cause
var plagueDeaths = window.MortalityState.getDeathsByCause('Plague');

// Get deaths by year
var deaths1250 = window.MortalityState.getDeathsByYear(1250);

// Get UI state and update
var uiState = window.MortalityState.getUIState();
window.MortalityState.updateUIState({
    filters: {
        genderFilter: 'male',
        ageGroupFilter: '61-70'
    }
});
```
