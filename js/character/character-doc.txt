## SYSTEM OVERVIEW

The Character System manages all characters in the game world, providing comprehensive CRUD operations, profession management, rank assignments, religion tracking, surname history, household history, soft delete functionality, bulk operations, random character generation, and character lifecycle management (birth, aging, death, inheritance).

**Key Design Principles:**
- **Single Source of Truth**: `character-state.js` holds all character data
- **Command-Query Separation**: Commands (writes) vs Queries (reads) separated
- **Separation of Concerns**: State, commands, queries, lifecycle, UI all separate
- **Recursion Guards**: All public functions protected from infinite loops
- **Change Notifications**: Subscriptions for reactive updates
- **No Emojis**: All icons from `icons.js` via `_getIcon()`
- **Soft Delete**: Non-destructive deletion with restore capability
- **Bulk Operations**: Create, update, delete multiple characters at once
- **Random Generation**: Fully automatic with cultural name support
- **Religion Integration**: Full religion assignment and conversion tracking
- **Complete Schema**: All character fields with history tracking
- **No Core Dependencies**: Character system depends on core, not the other way around

```javascript
// Create a random character
var result = CharacterCommands.createRandomCharacter({
    gender: 'male',
    age: 30,
    assignProfession: true
});
console.log('Created:', result.data.name, result.data.surname);

// Get character summary
var summary = CharacterQueries.getCharacterSummary('char_123');
console.log('Name:', summary.fullName);
console.log('Age:', summary.age);
console.log('Profession:', summary.primaryProfession?.name);

// Assign a religion
var religionResult = CharacterCommands.assignCharacterReligion('char_123', 'religion_christianity', {
    year: 1250,
    reason: 'conversion',
    notes: 'Converted by missionary'
});

// Get religion history
var history = CharacterCommands.getCharacterReligionHistory('char_123');

// Soft delete a character
var softResult = CharacterCommands.softDeleteCharacter('char_123');

// Restore a character
var restoreResult = CharacterCommands.restoreSoftDeletedCharacter('char_123');

// Purge all soft-deleted characters
var purgeResult = CharacterCommands.purgeSoftDeletedCharacters();

// Bulk create characters
var bulkResult = CharacterCommands.bulkCreateCharacters([
    { name: 'John', surname: 'Smith', gender: 'male', birthYear: 1220 },
    { name: 'Jane', surname: 'Doe', gender: 'female', birthYear: 1225 }
]);

// Get character statistics
var stats = CharacterQueries.getCharacterStatistics();
console.log('Total characters:', stats.total);
console.log('Living:', stats.living);
console.log('Literacy rate:', stats.literacyRate + '%');

// Kill a character
var deathResult = CharacterLifecycle.triggerNaturalDeath(character);
console.log('Died of:', deathResult.deathCause);

// Process inheritance
var inheritance = CharacterLifecycle.processHouseholdInheritance('char_123');

// Get family statistics
var familyStats = CharacterQueries.getCharacterFamilyStatistics('char_123');
console.log('Children:', familyStats.children.total);
console.log('Siblings:', familyStats.siblings.total);
console.log('Spouse:', familyStats.spouse?.character?.name);

// Get potential heirs
var heirs = CharacterLifecycle.getPotentialHeirs('char_123');
console.log('Heirs:', heirs.map(h => h.character.name + ' (' + h.relationship + ')'));
```
