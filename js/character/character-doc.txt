# CHARACTER SYSTEM - COMPLETE DOCUMENTATION

## SYSTEM OVERVIEW

The Character System is the foundation of the Still Waters simulation. It manages all character data, lifecycle events, and provides a clean API for other systems to interact with characters.

---

## FILE STRUCTURE

```
js/character/
├── character-state.js              # Single source of truth + cache + notifications
├── character-commands.js           # All write operations (create, update, delete, soft delete, bulk)
├── character-queries.js            # All read operations (search, filter, stats)
├── character-lifecycle.js          # Lifecycle business logic (birth, aging, death, inheritance)
├── character-ui-list.js            # UI list rendering
├── modals-character.js             # UI modals
└── character-doc.txt               # This documentation
```

---

## KEY PRINCIPLES

| Principle | Description |
|-----------|-------------|
| **Single Source of Truth** | `character-state.js` holds all character data |
| **Command-Query Separation** | Commands (writes) vs Queries (reads) separated |
| **Separation of Concerns** | State, commands, queries, lifecycle, UI all separate |
| **Recursion Guards** | All public functions protected from infinite loops |
| **Change Notifications** | Subscriptions for reactive updates |
| **No Direct masterData Access** | All access through the state layer |
| **No Emojis** | All icons from `core/icons.js` via `_getIcon()` |
