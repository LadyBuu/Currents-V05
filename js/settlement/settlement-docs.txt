## 3. RECURSION GUARDS

All modules implement recursion guards to prevent infinite loops:

| GUARD NAME | LOCATION | PURPOSE |
|------------|----------|---------|
| `_processingCommand` | settlement-commands.js | Prevent command re-entry |
| `_processingQuery` | settlement-queries.js | Prevent query re-entry |
| `_processingEconomy` | settlement-economy.js | Prevent economy re-entry |
| `_processingRanks` | settlement-ranks.js | Prevent rank processing re-entry |
| `_processingFeatures` | settlement-features.js | Prevent feature processing re-entry |
| `_rendering` | settlement-ui-list.js | Prevent rendering re-entry |
| `_openingModal` | All modals files | Prevent modal re-entry |
| `_initializingState` | settlement-state.js | Prevent state re-initialization |
| `_notifyingSubscribers` | settlement-state.js | Prevent subscriber re-entry |


## 4. ICON POLICY

All icons must come from icons.js via the `_getIcon()` function:

| RULE | DESCRIPTION |
|------|-------------|
| RULE 1 | NO emojis in code or UI |
| RULE 2 | All icons from icons.js via `_getIcon()` |
| RULE 3 | NO icons in confirm/cancel buttons (plain text only) |

**AVAILABLE ICONS USED BY SETTLEMENT SYSTEM:**

| CATEGORY | ICONS |
|----------|-------|
| Basic Shapes | CIRCLE, CIRCLE_DOT |
| UI Elements | HOME, PERSON, LOCATION, GEAR, TRASH |
| Status | SUCCESS, WARNING, DANGER |
| Objects | COIN, STAR_4 |


## 5. DATA STRUCTURES

### Settlement Data Object
```javascript
{
    rankId: string,                    // Rank ID (hamlet, village, town, city, metropolis)
    specializationRoleId: string,      // Role ID for specialization
    featureIds: [],                    // Array of feature IDs built
    prosperity: number,                // 0-100
    wealth: number,                    // Current wealth in gold
    totalDebt: number,                 // Current debt in gold
    foundedYear: number,               // Year founded
    lastUpgraded: number,              // Year last upgraded
    budget: {
        income: {
            taxes: number,
            trade: number,
            industry: number,
            stateEnterprises: number,
            other: number
        },
        expenses: {
            maintenance: number,
            wages: number,
            construction: number,
            military: number,
            education: number,
            infrastructure: number,
            other: number
        },
        annualSurplus: number,
        totalIncome: number,
        totalExpenses: number
    },
    employment: {
        totalWorkers: number,
        stateEmployed: number,
        privateEmployed: number,
        unemployed: number,
        averageWage: number,
        employmentRate: number
    },
    stateEnterpriseIds: [],            // Array of enterprise IDs
    taxRate: number,                   // Percentage (0-50)
    tradeTariff: number,               // Percentage (0-30)
    industryTaxRate: number,           // Percentage (0-30)
    militarySpending: number,          // Gold/year
    infrastructureSpending: number,    // Gold/year
    educationSpending: number,         // Gold/year
    justiceSeverity: string,           // 'lenient', 'medium', 'harsh', 'extreme'
    crimeRate: number,                 // 0-1
    hasWatch: boolean,
    watchSize: number,
    history: [],                       // Array of history entries
    notes: string
}
```

### Rank Object
```javascript
{
    id: string,                        // 'hamlet', 'village', 'town', 'city', 'metropolis'

}
```

### Feature Object
```javascript
{
    id: string,                        // Unique feature ID
    name: string,                      // Display name
    icon: string,                      // Icon symbol
    cost: number,                      // Build cost in gold
    defense: number,                   // Defense bonus
    maintenance: number,               // Annual maintenance cost
    prosperityBonus: number,           // Prosperity bonus
    crimeReduction: number,            // Crime reduction (0-1)
    tradeBonus: number,                // Trade income multiplier
    educationBonus: number,            // Education multiplier
    literacyBonus: number,             // Literacy bonus
    order: number,                     // Display order
    category: string,                  // 'defensive', 'civic', 'military', 'aesthetic', 'infrastructure'
    description: string,               // Description
    isPublic: boolean                  // Whether it's a public feature
}
```
