# COMPLETE SETTLEMENT SYSTEM DOCUMENTATION

## SYSTEM OVERVIEW

The Settlement System manages urban and rural settlements, tracking their economic, social, and infrastructural development. It handles rank progression, feature construction, budget management, employment, literacy, and **ROLE INTEGRATION**.

**KEY FEATURES:**
- Settlement rank progression (Hamlet → Village → Town → City → Metropolis)
- Public feature construction (walls, schools, markets, etc.)
- Economic management (income, expenses, surplus, debt)
- Employment tracking
- Literacy statistics
- **ROLE DISTRIBUTION** - Track professions at settlements
- **MASTER CONCENTRATION** - Track masters by role
- **PROSPERITY IMPACT** - Role diversity affects prosperity
- State enterprise management
- Justice system (crime rate, watch)
- Tax rate management
- Annual processing
- **PUBLIC ENTERPRISE MANAGEMENT** (NEW)
- **BUDGET ALLOCATION SYSTEM** (NEW)
- **EDUCATION SYSTEM INTEGRATION** (NEW)
- **GOVERNMENT SALARY ALLOCATION** (NEW)

## KEY PRINCIPLES

| Principle | Description |
|-----------|-------------|
| **Single Source of Truth** | `settlement-state.js` holds all settlement data |
| **Command-Query Separation** | Commands (writes) vs Queries (reads) separated |
| **Separation of Concerns** | State, commands, queries, economy, UI all separate |
| **Recursion Guards** | All public functions protected from infinite loops |
| **Change Notifications** | Subscriptions for reactive updates |
| **No Emojis** | All icons from `icons.js` via `_getIcon()` |
| **Role Integration** | Roles affect prosperity, tracked by settlement |
| **Budget Allocation** | Separate tracking for education, government salaries, infrastructure, military |
| **Public Enterprises** | Settlement-owned enterprises with profit collection |

## Annual Processing

### `SettlementCommands.processAnnualSettlementUpdate(locationId)`

| Property | Value |
|----------|-------|
| **Description** | Processes annual update for a single settlement |
| **Parameters** | `locationId` (string) |
| **Returns** | `Object` - Results including prosperity, surplus, wealth, debt |

**Processing Steps:**
1. Process state enterprises
2. Calculate income (taxes, trade, industry, state enterprises, public enterprises)
3. Calculate expenses (maintenance, wages, spending, government salaries)
4. Calculate surplus
5. Update wealth and debt
6. Apply debt interest (5% annually)
7. Update budget
8. Update prosperity (includes role factors, government leader, public enterprises)
9. Update employment
10. Update crime rate
11. Update rank (auto-upgrade if population threshold met)
12. Collect public enterprise profits
13. Save all changes

### `SettlementCommands.processAllSettlements()`

| Property | Value |
|----------|-------|
| **Description** | Processes annual update for all settlements |
| **Returns** | `{ success: boolean, processed: number, results: Array }` |

| **Average skill level** | +1-2% | **Role system** |
| **Underserved roles** | -1-3% | **Role system** |
| Government Leader | ±3-5% | Government system |
| **Public Enterprises** | +1-3% | **Public enterprise profit (NEW)** |

# 16. QUICK TEST COMMANDS

```javascript
// Get settlement summary
var summary = SettlementQueries.getSettlementSummary('loc_123');
console.log('Settlement:', summary.name, 'Rank:', summary.rank.name);

// Get budget allocation
var allocation = SettlementQueries.getSettlementBudgetAllocation('loc_123');
console.log('Education budget:', allocation.educationBudget);
console.log('Government salary budget:', allocation.governmentSalaryBudget);

// Get public enterprise summary
var publicSummary = SettlementQueries.getPublicEnterpriseSummary('loc_123');
console.log('Public enterprises:', publicSummary.total);
console.log('Total profit:', publicSummary.totalProfit);

// Get education stats
var eduStats = SettlementQueries.getSettlementEducationStats('loc_123');
console.log('Schools:', eduStats.totalInstitutions);
console.log('Students:', eduStats.totalStudents);
console.log('Coverage:', eduStats.coverageRatio + '%');

// Allocate education budget
var result = SettlementCommands.allocateEducationBudget('loc_123', 500, 1250);
console.log('Allocated 500 gold to education');

// Collect public enterprise profits
var profitResult = SettlementCommands.collectPublicEnterpriseProfits('loc_123', 1250);
console.log('Collected:', profitResult.totalProfit, 'gold');

// Process annual update
var annualResult = SettlementCommands.processAnnualSettlementUpdate('loc_123');
console.log('Prosperity:', annualResult.prosperity, 'Surplus:', annualResult.surplus);
console.log('Public enterprise profit:', annualResult.publicEnterpriseProfit);
```
