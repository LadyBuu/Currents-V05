# 1. SYSTEM OVERVIEW

## Purpose

The Settlement System manages all settlement-level data, economics, and government functions within the game world. It provides:

- **Settlement Data Management** - Create, read, update settlement data
- **Economic Simulation** - Income, expenses, surplus, wealth, debt
- **Feature Management** - Build, remove, demolish public features
- **Rank System** - Settlement ranks with population requirements
- **Specialization** - Settlements can specialize in specific roles
- **Employment Tracking** - Workers, unemployment, wages
- **Government Integration** - Government type, justice severity, watch
- **Budget Allocation** - Education, government salaries, infrastructure, military
- **State & Public Enterprises** - State-owned and public enterprises
- **Tax & Rate Management** - Tax rates, trade tariffs, industry taxes
- **Religious Integration** - Places of worship, dominant religion, religious unity
- **Civil Laws** - Settlement-defined civil laws (NEW)
- **Literacy Tracking** - Education levels, literacy rates
- **Annual Processing** - Yearly settlement updates

## Key Design Principles

| Principle | Description |
|-----------|-------------|
| **Single Source of Truth** | `settlement-state.js` holds all settlement data |
| **Command-Query Separation** | Commands (writes) vs Queries (reads) separated |
| **Separation of Concerns** | State, commands, queries, economy, UI all separate |
| **Recursion Guards** | All public functions protected from infinite loops |
| **Change Notifications** | Subscriptions for reactive updates |
| **No Emojis** | All icons from `icons.js` via `_getIcon()` |
| **Civil Laws** | Settlements define their own civil laws |

# 6. SETTLEMENT-COMMANDS-ANNUAL.JS

## Purpose

Annual processing for settlements - updates wealth, budget, prosperity, employment, crime rate, rank, and religion.

## Dependencies

| Module | Functions Used |
|--------|----------------|
| `settlement-commands-core.js` | Infrastructure |
| `settlement-state.js` | `SettlementState` |
| `settlement-economy.js` | `SettlementEconomy` |

## Key Functions

| Function | Parameters | Returns | Description |
|----------|------------|---------|-------------|
| `processAnnualSettlementUpdate(locationId)` | string | Object | Processes annual update for a settlement |
| `processAllSettlements()` | None | Object | Processes all settlements |

**Annual Processing Steps:**

1. Process state enterprises
2. Calculate income (tax, trade, industry, state enterprises, public enterprises)
3. Calculate expenses (maintenance, wages, spending, government salaries)
4. Calculate surplus
5. Update wealth
6. Apply debt interest (5% annually)
7. Update budget
8. Update prosperity
9. Update employment
10. Update crime rate
11. Update rank (auto-upgrade if population threshold met)
12. Update dominant religion
13. Collect public enterprise profits
14. Save all changes

# 26. USAGE EXAMPLES

## Example 1: Getting Settlement Data

```javascript
// Get settlement data
var data = window.SettlementState.getSettlementData('loc_123');
console.log('Prosperity:', data.prosperity);
console.log('Wealth:', data.wealth);
console.log('Rank:', data.rankId);

// Get all settlements
var allSettlements = window.SettlementState.getAllSettlements({
    sortBy: 'prosperity',
    sortOrder: 'desc'
});
```

## Example 2: Building a Feature

```javascript
// Build a feature
var result = window.SettlementCommands.buildFeature('loc_123', 'school');
if (result.success) {
    console.log('School built!');
    console.log('New wealth:', result.data.newWealth);
}

// Remove a feature (full refund)
var removeResult = window.SettlementCommands.removeFeature('loc_123', 'school');
if (removeResult.success) {
    console.log('School removed, refund:', removeResult.data.refund);
}

// Demolish a feature (no refund)
var demolishResult = window.SettlementCommands.demolishFeature('loc_123', 'walls');
if (demolishResult.success) {
    console.log('Walls demolished');
}
```

## Example 3: Upgrading a Settlement

```javascript
// Check if upgrade is possible
var upgradeInfo = window.SettlementQueries.getUpgradeInfo('loc_123');
console.log('Can upgrade:', upgradeInfo.canUpgrade);
console.log('Next rank:', upgradeInfo.nextRank);

// Perform upgrade
if (upgradeInfo.canUpgrade) {
    var result = window.SettlementCommands.upgradeSettlement('loc_123');
    if (result.success) {
        console.log('Upgraded from', result.data.oldRank, 'to', result.data.newRank);
    }
}
```

## Example 4: Managing Civil Laws (NEW)

```javascript
// Add a civil law
var lawData = {
    name: 'No Murder',
    description: 'Murder is illegal in this settlement',
    type: 'law',
    domain: 'violence',
    severity: 'mortal',
    crimeType: 'murder',
    punishment: 'Execution',
    isEnforced: true
};

var result = window.SettlementCommands.addCivilLaw('loc_123', lawData);
if (result.success) {
    console.log('Law added:', result.data.name);
}

// Get all civil laws
var laws = window.SettlementCommands.getCivilLaws('loc_123');
for (var i = 0; i < laws.length; i++) {
    console.log(laws[i].name, '-', laws[i].severity);
}

// Update a civil law
var updateResult = window.SettlementCommands.updateCivilLaw('loc_123', lawId, {
    punishment: 'Life Imprisonment'
});

// Remove a civil law
var removeResult = window.SettlementCommands.removeCivilLaw('loc_123', lawId);
```

## Example 5: Managing Budget and Taxes

```javascript
// Set tax rate
window.SettlementCommands.updateTaxRate('loc_123', 15);

// Set trade tariff
window.SettlementCommands.updateTradeTariff('loc_123', 10);

```

## Example 6: Managing State Enterprises

```javascript
// Create a state enterprise
var result = window.SettlementCommands.createStateEnterprise('loc_123', {
    name: 'Royal Weavers',
    typeId: 'weaving',
    wealth: 500,
    workerCount: 20
});

if (result.success) {
    console.log('Enterprise created:', result.data.name);
}

// Get public enterprise summary

```

## Example 7: Managing Justice and Watch

