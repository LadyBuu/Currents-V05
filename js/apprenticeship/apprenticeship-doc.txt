## SYSTEM OVERVIEW

The Apprenticeship System manages the master-apprentice relationships where characters learn professions and skills from more experienced practitioners. It handles skill progression, teaching sessions, knowledge preservation on death, and finding masters by location.

**Key Principles:**
- **Consolidated Architecture:** Single file (`apprenticeship-system.js`) delegates all functionality to `ProfessionalLogic`
- **No Trust System:** All trust-related functionality has been removed
- **Direct Learning:** Skills are taught directly through teaching sessions
- **Skill Progression:** Skill levels range from 0-100 with defined stages
- **Master-Apprentice Relationships:** Stored as relationship records
- **Knowledge Preservation:** Skills can be passed on through inheritance/teaching
- **Location-Based Discovery:** Find masters in settlements

## APPRENTICESHIP-MODALS.JS

**PURPOSE:** UI modals for apprenticeship management.

### Modal Functions

| Function | Parameters | Returns | Description |
|----------|------------|---------|-------------|
| `openCreateApprenticeshipModal(master, candidate, onSuccess)` | `master`, `candidate`, `onSuccess` | None | Creates apprenticeship |
| `openEditApprenticeshipModal(masterId, apprenticeId, onSuccess)` | `masterId`, `apprenticeId`, `onSuccess` | None | Edits apprenticeship |
| `openApprenticeshipDetailsModal(masterId, apprenticeId, onSave, onDelete)` | `masterId`, `apprenticeId`, `onSave`, `onDelete` | None | Shows apprenticeship details |
| `openViewMasterTreeModal(masterId, onRefresh)` | `masterId`, `onRefresh` | None | Shows master tree |
| `openFindMasterByLocationModal(locationId, roleId, onSuccess)` | `locationId`, `roleId`, `onSuccess` | None | Finds masters by location |

### Modal Features

**Create Apprenticeship Modal:**
- Master and candidate info display
- Profession to learn selection (from teachable skills)
- Start year input
- Initial skill level input (0-100)
- Move options (apprentice to master, master to apprentice, separate)
- Household assignment options
- Notes field

**Edit Apprenticeship Modal:**
- Master and apprentice info
- Current skill display
- Start year edit
- Skill level edit (0-100)
- Status dropdown (ongoing, completed, ended)
- Notes edit
- Quick action buttons: +5 Skill, Complete

**Apprenticeship Details Modal:**
- Full apprenticeship information display
- Profession, skill level, start year, duration
- Status badge
- Action buttons: Edit, +5 Skill, Complete, Terminate, Delete

**View Master Tree Modal:**
- Master info display
- List of all apprentices with skill levels and status
- Click on apprentice to view details

**Find Master by Location Modal (NEW):**
- Settlement selection
- Role filter (optional)
- List of masters with apprentice counts
- Click on master to select
