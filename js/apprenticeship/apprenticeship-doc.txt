# APPRENTICESHIP SYSTEM - COMPLETE DOCUMENTATION

## SYSTEM OVERVIEW

The Apprenticeship System manages the master-apprentice relationship for skill transfer and professional development. It handles the creation, progression, and completion of apprenticeships, with skill tracking and stage-based progression.

**KEY FEATURES:**
- Master-apprentice relationship management
- Skill progression through defined stages (Novice → Apprentice → Journeyman → Master)
- Automatic annual skill advancement
- Teaching sessions and skill transfer
- Knowledge preservation on death
- Full UI integration with character and role systems

---

## KEY PRINCIPLES

| Principle | Description |
|-----------|-------------|
| **NO TRUST SYSTEM** | Trust has been completely removed from the apprenticeship system |
| **Consolidated Architecture** | All functionality delegates to `ProfessionalLogic` |
| **Relationship-Based** | Apprenticeships are stored as relationship records |
| **Command-Query Separation** | Commands (writes) vs Queries (reads) separated |
| **Separation of Concerns** | Constants, modals, and system wrapper all separate |
| **Recursion Guards** | All public functions protected from infinite loops |
| **No Emojis** | All icons from `icons.js` via `_getIcon()` |

## Modal Functions

### `openCreateApprenticeshipModal(master, candidate, onSuccess)`

| Property | Value |
|----------|-------|
| **Description** | Opens modal to create a new apprenticeship |
| **Parameters** | `master` (Object), `candidate` (Object), `onSuccess` (function) |
| **Returns** | void |

**Modal Features:**
- Displays master and candidate information
- Shows location comparison (with move options)
- Profession selection from master's teachable skills
- Start age and start year selection
- Skill level slider (0-100)
- Move options (apprentice to master, master to apprentice, keep separate)
- Household assignment options
- Notes field

**Move Options:**
| Option | Description |
|--------|-------------|
| `apprentice` | Move apprentice to master's location |
| `master` | Move master to candidate's location |
| `separate` | Keep separate residences |

**Household Assignment Options:**
| Option | Description |
|--------|-------------|
| `master` | Move apprentice to master's household |
| `separate` | Keep independent household |
| `none` | No household change |
