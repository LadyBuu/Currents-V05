# 1. SYSTEM OVERVIEW

## Purpose

The Culture System is a **flavor and appearance system** that provides:

- **Weighted appearance templates** for characters (skin, eyes, hair, height, build)
- **Mythology flavor text** for worldbuilding (creation stories, deities, symbols)
- **Location association** - cultures are tied to locations
- **Character integration** - when a character is created, appearance is rolled from their location's culture

## What It Replaces

The hardcoded appearance defaults in `character-commands.js` `createRandomCharacter()`:

```javascript
// OLD - hardcoded
appearance: {
    hairColor: _pickRandom(['Blonde', 'Brown', 'Black', 'Red', 'Gray']),
    eyeColor: _pickRandom(['Blue', 'Green', 'Brown', 'Gray', 'Hazel']),
    height: _pickRandom(['Short', 'Average', 'Tall'])
}

// NEW - from culture template
appearance: generateAppearance(cultureId, gender)
// Result: { skinTone: 'Fair', eyeColor: 'Blue', hairColor: 'Blonde', 
//           hairType: 'Wavy', build: 'Average', height: 178 }
```

## Key Principles

| Principle | Description |
|-----------|-------------|
| **Pure Flavor** | Cultures provide appearance and mythology - no gameplay impact |
| **Weighted Randomization** | Appearance traits are rolled from weighted probabilities |
| **Location Inheritance** | Characters inherit culture from their birthplace location |
| **Separation from Religion** | Culture is independent from religion (though they can be associated) |
| **No Emojis** | All icons from `icons.js` via `_getIcon()` |
| **Command-Query Separation** | Commands (writes) vs Queries (reads) separated |
| **Recursion Guards** | All public functions protected from infinite loops |

## Culture vs Religion

| Feature | Religion System | Culture System |
|---------|-----------------|----------------|
| Beliefs | Yes (traits, laws) | No (mythology is flavor) |
| Leadership | Yes (leader, clergy) | No |
| Laws | Yes (enforceable) | No (traditions are flavor) |
| Inheritance | Yes (configurable) | No |
| Appearance | No | Yes (weighted probabilities) |
| Mythology | No | Yes (flavor text) |
| Locations | Associated | Associated |
| Schools | Yes (religious schools) | No |
| Places of Worship | Yes | No |
| Gameplay Impact | High | None (pure flavor) |

## Dependencies

| Module | Functions Used |
|--------|----------------|
| `storage.js` | `masterData`, `saveMasterData` |

## State Structure

```javascript
_state = {
    cultures: [],
    cache: {
        byId: new Map(),        // cultureId → culture
        byName: new Map(),      // name → [cultures]
        byLocation: new Map(),  // locationId → [cultures]
        byReligion: new Map()   // religionId → [cultures]
    },
    subscribers: [],

};
```

# 7. CULTURE-GENERATION.JS

## Purpose

Weighted appearance generation from culture templates.

## Dependencies

| Module | Functions Used |
|--------|----------------|
| `culture-state.js` | `CultureState` |
| `culture-queries.js` | `CultureQueries` |
| `randomness.js` | `pickWeighted`, `randomInt`, `pickRandom` |

## Key Functions

### Weighted Roll Functions

| Function | Parameters | Returns | Description |
|----------|------------|---------|-------------|
| `rollWeightedValue(options, defaultValue)` | Array, * | * | Rolls a weighted value from options |
| `rollWeightedValues(options, count, defaultValue)` | Array, number, * | Array | Rolls multiple weighted values |
| `rollHeight(heightConfig, gender, defaultMin, defaultMax)` | Object, string, number, number | number | Rolls height within gender-specific ranges |

### Appearance Generation

| Function | Parameters | Returns | Description |
|----------|------------|---------|-------------|
| `generateAppearanceFromCulture(culture, gender, options)` | Object, string, Object | Object | Generates appearance from culture object |
| `generateAppearance(cultureId, gender, options)` | string, string, Object | Object | Generates appearance from culture ID |
| `generateAppearanceForLocation(locationId, gender, options)` | string, string, Object | Object | Generates appearance for a location |
| `generateAppearanceWithRandomCulture(gender, options)` | string, Object | `{ culture, appearance }` | Generates appearance with random culture |

### Location Culture Helpers

| Function | Parameters | Returns | Description |
|----------|------------|---------|-------------|
| `findCultureForLocation(locationId)` | string | Object\|null | Finds culture for a location |
| `findAllCulturesForLocation(locationId)` | string | Array | Gets all cultures for a location |

## Appearance Generation Flow

```
1. Get culture by ID or location
   ↓
2. Extract appearance config from culture
   ↓
3. For each category (skin, eyes, hair, etc.):
   a. If culture has options, roll weighted value
   b. Otherwise use default options
   ↓
4. For height:
   a. Use gender-specific ranges from culture
   b. Roll random height within range
   ↓
5. For common features:
   a. Roll 1-2 features from culture's commonFeatures
   ↓
6. Return appearance object
```

## Culture ↔ Character Generation Flow

```
1. Character creation triggered
   ↓
2. Birthplace location selected (or random)
   ↓
3. Culture lookup: find culture for location
   ├── Check if location has cultureId directly
   ├── If not, walk up hierarchy to find parent with culture
   └── If none found, use default culture
   ↓
4. Appearance generation:
   ├── If culture found, use its appearance template
   ├── Roll weighted values for each category
   ├── Roll height within gender-specific range
   └── Roll 1-2 common features
   ↓
5. Character created with cultureId and appearance
```

# 16. USAGE EXAMPLES

## Creating a Culture

```javascript
var result = window.CultureCommands.createCulture({
    name: 'Nordic',
    displayName: 'Nordic Peoples',
    description: 'The hardy peoples of the cold north',
    icon: '✦'
});

if (result.success) {
    console.log('Created culture:', result.data.name);
}
```

## Adding Appearance Options

```javascript
var result = window.CultureCommands.addAppearanceOption(
    'culture_123',
    'skinTones',
    { value: 'Pale', weight: 70 }
);

if (result.success) {
    console.log('Appearance option added');
}
```

## Updating Appearance Weight

```javascript
var result = window.CultureCommands.updateAppearanceWeight(
    'culture_123',
    'skinTones',
    'Pale',
    80
);

if (result.success) {
    console.log('Weight updated');
}
```

## Generating Appearance

```javascript
var appearance = window.CultureGeneration.generateAppearance(
    'culture_123',
    'male'
);

console.log('Skin:', appearance.skinTone);
console.log('Eyes:', appearance.eyeColor);
console.log('Hair:', appearance.hairColor);
console.log('Height:', appearance.height);
```

## Getting Culture by Location

```javascript
var culture = window.CultureQueries.getCultureByLocation('loc_456');
if (culture) {
    console.log('Culture at location:', culture.name);
}
```

## Creating Character with Culture

```javascript
// CharacterCommands.createRandomCharacter now uses culture automatically
var result = window.CharacterCommands.createRandomCharacter({
    birthplaceId: 'loc_456',  // Culture will be looked up from location
    gender: 'male'
});

if (result.success) {
    console.log('Character:', result.data.name);
    console.log('Culture:', result.data.cultureId);
    console.log('Appearance:', result.data.appearance);
}
```

## Getting Culture Statistics

```javascript
var stats = window.CultureQueries.getCultureStatistics();
console.log('Total cultures:', stats.total);
console.log('With locations:', stats.withLocations);
console.log('With religions:', stats.withReligions);
console.log('With mythology:', stats.withMythology);
```

## Rendering Culture List

```javascript
window.CultureUI.renderCultureList('myContainer', {
    onSelect: function(culture) {
        console.log('Selected:', culture.name);
    },
    showLocations: true,
    showReligions: true,
    showMythology: true
});
```

## Associating Culture with Location

```javascript
// First add location to culture
var result = window.CultureCommands.addLocationToCulture(
    'culture_123',
    'loc_456'
);

// Then assign culture to location (via LocationCommands)
var result2 = window.LocationCommands.updatePlaceCulture(
    'loc_456',
    'culture_123'
);
```
